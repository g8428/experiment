# <프로젝트명>

새 프로젝트를 시작할 때 이 폴더(`projects/_template/`)를 `projects/<프로젝트명>/`으로 복사하고 아래와 `TEAM.md`를 채운다. 팀 구성·검증·출시 방법은 `TEAM.md`에, 실행 명령과 세부 규칙은 이 파일에 쓴다. 루트 `AGENTS.md` 팀 명부에도 한 줄 추가한다.

## 브랜치

`project/<프로젝트명>` (팀장이 첫 작업 때 만든다.)

## 목표

- 이 프로젝트가 해결하려는 문제는 무엇인가 (한두 문장)
- 완료 기준은 무엇인가 (구체적으로: 어떤 파일/기능/자동화가 존재하면 끝인지)

## 제약/전제

- 예: 사용 가능한 API, 예산, 마감, 반드시 지켜야 할 형식 등

## 실행 방식

- [ ] 개발 중 — 팀장 세션이 레인으로 나눠 개발한다
- [ ] 졸업 — 예약 루틴이나 GitHub Actions로 반복 실행만 한다 (운영팀 관리)

## 진행 로그

날짜별로 무엇을 했는지 한두 줄씩 (커밋 해시 포함 권장).

- YYYY-MM-DD: (예시) 초기 스캐폴딩 생성, commit xxxxxxx
