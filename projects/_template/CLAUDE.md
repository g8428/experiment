# <프로젝트명>

새 프로젝트를 시작할 때 이 폴더(`projects/_template/`)를 `projects/<프로젝트명>/`으로 복사하고 아래를 채운다.

## 브랜치

`project/<프로젝트명>` (project-lead가 시작할 때 자동으로 만든다. 아직 없다면 만들 것.)

## 목표

- 이 프로젝트가 해결하려는 문제는 무엇인가 (한두 문장)
- 완료 기준은 무엇인가 (구체적으로: 어떤 파일/기능/자동화가 존재하면 끝인지)

## 제약/전제

- 예: 사용 가능한 API, 예산, 마감, 반드시 지켜야 할 형식 등

## 실행 방식

- [ ] 헤드봇(Cowork 스케줄 태스크)으로 반복 실행되는 작업인가?
- [ ] 프로젝트 에이전트(로컬 Claude Code)가 개발하는 작업인가?

## 진행 로그

날짜별로 무엇을 했는지 한두 줄씩 (커밋 해시 포함 권장).

- YYYY-MM-DD: (예시) 초기 스캐폴딩 생성, commit xxxxxxx
