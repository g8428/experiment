## 0. BTC 적용 원칙 (강의 근거)

### 0-1. 강의에서 BTC/24시간 시장에 대해 직접 말한 것
- **8강**: 1~6강의 BOS/CHoCH/IDM 매핑은 인도 지수용이다. 포렉스·비트코인에는 **ITH/ITL/STH/STL 매핑**을 써야 한다. BOS/IDM 방식은 24시간 시장에서 조작에 더 취약하다.
- **8강**: 24시간 시장은 캔들과 구조가 훨씬 많이 생긴다. 그래서 **세션(킬존) 안에서만 매매**하고, 세션 밖 매매는 의미 없다.
- **8강**: 권장 TF는 **4H = 3캔들 포메이션(방향 컨펌), 1H = 구조 매핑**, 진입은 하위TF다.
- **7강 이후 개념 전부**(블록, 바이어스, 프랙탈)는 포렉스·비트코인·인도 시장 공통이다.
- **10강**: 사상 최고가 구간에서는 3캔들 스윙(또는 결정적 캔들)이 생기기 전엔 반전하지 않는다.

### 0-2. 인도 시장 전용이라 BTC에서 버리거나 바꾸는 것
| 강의 개념 | BTC 처리 |
|---|---|
| 갭업/갭다운 오프닝, Gap Imbalance, Liquidity Void | 24시간 시장이라 일봉 갭이 없다. 하위TF의 **Volume Imbalance**(몸통 사이 공백)로만 대체한다 |
| "아래 POI 없으면 갭업" (9강 데일리 바이어스) | "아래 POI 없으면 **일봉 시가 직후 바로 확장**"으로 읽는다(9강의 '시가부터 확장' 예외와 같은 논리) |
| 인도 장 시가 9:15 | **일봉 시가 = 00:00 UTC (KST 09:00)**. `[미정의]` 거래소 일봉 기준 시각과 맞출 것 |
| BTST(익일 보유) | 해당 없음 |

### 0-3. 세션 시간 (10강 뉴욕시간 → KST 변환)
뉴욕 서머타임(UTC-4) 기준이다. 겨울(UTC-5)에는 KST가 **+1시간** 늦어진다.

| 구간 | 뉴욕시간 | KST (서머타임) |
|---|---|---|
| Asian 킬존 | 20:00–24:00 | 09:00–13:00 |
| London 킬존 | 02:00–05:00 | 15:00–18:00 |
| New York 킬존 | 07:00–10:00 | 20:00–23:00 |
| London Close | 10:00–12:00 | 23:00–01:00 |
| CBDR 박스 | 14:00–20:00 | 03:00–09:00 |
| '3:30~8' 아시안 진입 표시 구간 | 15:30–20:00 | 04:30–09:00 |
| 런던클로즈 이후 매매 금지 | 12:00~ | 01:00~ |

> 강의의 세션 전략(10강)은 포렉스·금으로 설명됐다. BTC 효과는 강의가 보장하지 않으므로 **검증 대상**으로 분류한다.

## 1. 데이터·TF 계층

| 계층 | TF | 역할 (강의 근거) |
|---|---|---|
| Macro | 월봉 | 시가 기준 방향, 월 목표 (9강) |
| Intermediate | 주봉 | 주 시가, 전주 고저, 주간 장애물 (9강) |
| Short-term | 일봉 | 일 시가, 데일리 바이어스, 일봉 POI (9·10강) |
| 방향 컨펌 | 4H | 3캔들 포메이션, 풀백 구역 (8·11강) |
| 구조 매핑 | 1H | ITH/ITL/STH/STL, MSS 판정 (8·11강) |
| 실행 | 15m | 진입 TF 기준 (10강: "15m가 기준 TF") |
| 정밀 실행 | 5m, 1m | Refined OB, displacement·MSS 확인 (4·6강) |

**원칙**: 분석은 반드시 위에서 아래로 한다(9강). 하위TF에서 상위TF로 올라가면 방향을 틀린다. 상위TF가 하위TF의 '주인'이다(11강).

## 2. 기본 요소 정의 (코드화용)

모든 판정은 **완결된 봉**으로만 한다.

### 2-1. 캔들 묶기
- **인사이드바**: 고가 ≤ 직전 고가이고 저가 ≥ 직전 저가인 캔들. 모(母)캔들과 하나로 묶는다(3·4·7강). 인사이드바로 만든 3캔들 스윙은 무효다(8강).

### 2-2. 스윙
- **3캔들 스윙 저점**: 가운데 캔들 저가 < 좌·우 캔들 저가. 고점은 대칭(8강).
- **ITH**: 3캔들 스윙 고점 중, 그 왼쪽과 오른쪽에 **각각 더 낮은 3캔들 스윙 고점**이 있는 것. ITL은 대칭(8·11강).
  - 확정 시점 = 오른쪽 스윙이 완성된 봉.
- **STH/STL**: ITH와 ITL 사이에서 생기는 그 밖의 스윙(8강).

### 2-3. 구조 깨짐
- **돌파 인정**: 몸통 종가가 레벨 너머로 마감해야 한다. 꼬리만 넘으면 **스윕**이다(3·5강).
  - 꼬리가 생기면 이후 캔들은 그 꼬리 끝 너머로 몸통 마감해야 돌파다(3강).
- **MSS**: 직전 반대 방향 스윙(왼쪽 스윙)을 몸통으로 돌파하는 것. **1H 이상에서 난 MSS만 방향 판단에 쓴다.** 하위TF MSS는 트랩일 수 있어 진입 트리거로만 쓴다(11강).

### 2-4. PD 배열 (가격이 반응하는 구역)
| 이름 | 정의 | 진입 기준가 |
|---|---|---|
| **FVG** | 상승: 캔들1 고가 < 캔들3 저가, 그 사이 구간(4강). 크기 무관 | 구간 |
| **Volume Imbalance (VI)** | 인접 캔들의 **몸통끼리 겹치지 않고 꼬리만 겹치는** 구간(6강) | 구간, 50%(MT) |
| **BPR** | 반대 방향 FVG 두 개가 겹친 구간(8강) | 겹친 구간 |
| **OB (기본)** | 강한 움직임 직전 마지막 반대 캔들(가장 깊은 저가 캔들, 색 무관). **바로 붙은 FVG 필수.** FVG가 없으면 FVG가 붙은 다음 캔들로 이동(4강) | OB 전체 또는 50% |
| **Advanced OB** | FVG 없이 연속된 마지막 반대색 캔들 묶음. 사이에 반대색이 끼면 끊는다(인사이드바면 묶음)(7강) | **50%(MT)**. 몸통이 MT 너머 마감하면 무효 |
| ↳ 겹침 규칙 | OB 꼬리가 **미충전 FVG와 겹치면** MT까지 오지 않는다. 그 꼬리+FVG 구간에서 진입. FVG가 이미 채워졌으면 OB 전체/MT 사용(7강) | 꼬리+FVG |

### 2-5. 블록 (7강)
| 블록 | 조건 | 진입 |
|---|---|---|
| **Mitigation** | 스윙 실패: 상승에서 HH는 깨지는데 HL은 못 깸 → 깨진 직전 HH의 마지막 음봉(최고점 캔들) | 되돌아올 때 매수. **FVG/OB와 겹칠 때만** |
| **Breaker** | 하락: 고점(BSL) 스윕 → 저점(SSL) 이탈 → 그 고점 스윙의 블록으로 복귀. 상승 대칭 | 블록 탭 시. 스윙 내부가 같은 색 캔들뿐이면 50% |
| **Rejection** | 스윙 극점의 긴 꼬리. 1~5m는 꼬리 2개 이상, 30m 이상은 1개 | 꼬리 구간 50%. **MT 너머 몸통 마감 = 무효** |
| **Reclaimed** | 상위TF POI로 가는 느린 레그 → POI 도달 → displacement+MSS → 진입 레그 왼쪽 스윙들의 블록 재탭 | 블록마다 순차 진입 |

- 블록은 반드시 **상위TF 맥락**(PDH/PDL 스윕, 상위TF POI, 극단 POI)이 있을 때만 쓴다(7강).

### 2-6. 유동성 (5·11강)
- **ERL**(외부): 1H/4H/일봉 스윙 고저, PDH/PDL, PWH/PWL, 전월 고저.
- **IRL**(내부): 1m~15m 스윙, 추세선, 동일 고/저. `[미정의]` 동일 고/저 허용 오차 → 기본값 후보: 0.05% 또는 0.1×ATR(15m).
- **규칙**:
  - 가격은 IRL을 먼저 가져간 뒤 ERL로 간다.
  - **유동성이 앞에 없는 POI는 깨진다.**
  - 두 ERL 중 바이어스 쪽 하나만 깨진다.

### 2-7. Displacement (6·11강)
- 정의: **FVG가 연달아 생기는 레그**. 강의의 표현은 "1m 캔들 하나가 평소 5m 캔들보다 큼"이다.
- `[미정의]` 수치화 기본값 후보:
  - 레그 안 FVG ≥ 2개, 그리고
  - 레그 최대 캔들 범위 ≥ 2 × ATR(같은 TF, 20).
- **가짜 레그**: 상위TF POI 도달 직후 FVG/OB 없이 장대 2~3개만 나온 레그 → 진입 금지(6강).
- **인듀스먼트**: 바이어스 반대 방향으로 캔들끼리 절반 이상 겹치며 느리게 움직이는 레그. 그 안에서 생긴 OB는 깨진다(11강).
  - `[미정의]` 겹침 비율 기본값: 연속 캔들 몸통 겹침 ≥ 50%가 5봉 이상.

### 2-8. 프리미엄/디스카운트 (7·10·11강)
- 대상 레그(또는 딜링 레인지)에 피보 0 / 0.5 / 1을 그린다. 0.5 위 = 프리미엄, 아래 = 디스카운트.
- 상승 바이어스면 **디스카운트의 PD 배열에서만 매수**한다. 하락은 대칭이다.
- OTE 구간: 0.62~0.79(10강).

## 3. 바이어스 엔진 (9·10·11강) — 모든 전략의 공통 입력

출력은 방향(long/short/none)과 목표가 목록이다.

### B1. 월 → 주 → 일 시가 규칙 (9강)
- 상위 구조가 상승이면 **해당 봉 시가 아래에서만 매수**한다. 하락이면 시가 위에서만 매도한다.
- 월봉 판정:
  - 월봉 POI(FVG/VI/OB)를 탭하고 displacement가 나왔으면 다음 달 바이어스 = 반대 방향이다.
  - 월 목표 = 반대편 유동성이다.
- 그 달 동안 반대 방향 진입은 찾지 않는다.
- 단, 일봉 OB나 주봉 리젝션/VI 같은 **장애물에서 임시 되돌림**이 온다 → 장애물 레벨을 같이 표시하고, 그 구간 진입은 보류한다.

### B2. 데일리 바이어스 (9강)
| 오늘 일봉 | 내일 바이어스 / 목표 |
|---|---|
| 전일 저점 스윕 + 전일 저점 위 마감 | 상승 / 오늘 고점 |
| 전일 고점 스윕 + 전일 고점 아래 마감 | 하락 / 오늘 저점 |
| 스윕 없이 전일 고점 위 종가 마감 (지속형) | 상승 지속 (상위 바이어스 완료까지) |
| 스윕 없이 전일 저점 아래 종가 마감 | 하락 지속 |

- 상위 바이어스 **반대** 방향의 데일리 신호는 약하다 → 목표를 전부 채우지 않고 **그 봉 안의 마지막 POI만 탭하고 복귀**한다. 목표를 짧게 잡는다.
- 전일 봉이 큰 확장봉이면 → 다음 날은 그 안의 OB로 되돌림이 우선이다.
- 주간도 같은 규칙이다: PWH 스윕 후 주봉이 아래로 마감하면 다음 주 하락이고, 목표는 주간 VI다.

### B3. 일봉 내러티브·3B (10강)
- **B1(최근 행동)**: 최근 유동성을 스윕했거나 PD 배열을 탭했는가?
- **B2(다음 목표)**: 그 반대 방향의 첫 대상(FVG/OB, 없으면 반대편 유동성)이다.
- **B3(위치)**: 현재 딜링 레인지에서 프리미엄인가 디스카운트인가?
- 도지 등 불명확하면 바이어스는 none이다(매매 안 함).

### B4. 딜링 레인지 (9강)
- **SSL과 BSL을 모두 사냥한 레그** = 딜링 레인지(순서 무관).
- 상승 레인지: 디스카운트의 마지막 PD 배열에서 매수, 목표는 레인지 고점. 하락은 대칭.
- 2~4주 바이어스로 쓴다. 상위(월) 바이어스가 받쳐줄 때 신뢰도가 높다.

### B5. 4H 3캔들 포메이션 (8강)
- 상위TF(4H/일봉) POI에서 3캔들 스윙이 생기면 → 방향 전환 컨펌이다.
- 다음 미탭 POI(다음 목표)까지 **직전 3캔들 스윙은 몸통으로 깨지지 않는다**(꼬리 스윕은 허용).
- POI 부근 FVG가 여러 겹이면 장기 전환, 하나뿐이면 단기 전환이다.

### B6. 바이어스 무효
- 상승 바이어스인데 **1H/4H ITL이 몸통으로 깨지면** 바이어스를 잘못 본 것이다 → 하락으로 전환(8·11강).
- STL만 깨지면 임시 되돌림이다(STL~ITL 사이 POI까지).

### B7. 사상 최고가 규칙 (10강)
- BTC가 ATH 구간이면, 3캔들 스윙(또는 결정적 캔들)이 생기기 전엔 숏 바이어스를 내지 않는다.

## 4. 전략 (BTC 적합도 순)

모든 전략의 공통 전제:
- 바이어스 엔진 방향 ≠ none.
- 진입 방향 = 바이어스 방향. 단 '카운터'로 명시된 것은 예외이고, 목표를 짧게 잡는다.
- 진입 시각이 킬존 안이다(8강 "24시간 시장은 세션만"). `[미정의]` 킬존 필터를 전 전략에 강제할지 → 강의 문구상 강제가 기본, 검증으로 비교한다.
- 진입가가 프리미엄/디스카운트 규칙을 만족한다.

### ★ S1. ITH/ITL 레인지 매매 — 강의가 BTC에 직접 권장 (8·11강)
| 단계 | 규칙 |
|---|---|
| 방향 | B1~B5. 특히 4H 3캔들 포메이션 + 다음 미탭 POI(목표) 확정 |
| 구조 | **1H에서만** ITH/ITL/STH/STL을 매핑한다. 15m에서는 **1H STL = 15m ITL**, 1H STH = 15m ITH로만 쓴다. 그 외 15m ITH/ITL은 트랩이므로 무시 |
| 진입 구역 | (상승) ITL 확정 후 ITH~ITL 피보 0.5 아래 디스카운트의 PD 배열: FVG, BPR, 미티게이션+FVG, Advanced OB의 MT. 겹칠수록 우선 |
| 대체 진입 | 디스카운트에 POI가 없으면 **ITL 꼬리 스윕**(몸통 마감 없음)을 근거로 진입 |
| 트리거 | 15m 해당 구역 탭 + 거부 (또는 1m/5m 0-3 진입 모듈) |
| SL | ITL 아래 + 버퍼. `[미정의]` 버퍼 기본값: 0.1×ATR(1H). 몸통이 ITL 아래로 마감하면 즉시 청산 |
| TP | ITH (상승 바이어스 중엔 ITH가 '반드시' 깨진다는 규칙) |
| 트레일 | ITL 이후 생긴 STL 아래 (ITH 돌파 전까지 안 깨진다는 규칙) |
| 종료 | 목표 POI(바이어스) 도달 시 역할 교대 → 반대 방향 ITH/ITL 매매로 전환 |
| 하락 | 전부 대칭 (ITH 위 SL, TP = ITL) |

### ★ S2. 진입 모듈 — 상위TF POI 반전/지속 (6·11강)
| 단계 | 규칙 |
|---|---|
| 1. HTF POI | 바이어스 방향의 4H/일봉 POI(OB, FVG, VI, BPR, 극단 OB)에 가격 도달 |
| 2. 가짜 레그 필터 | 도달 직후 FVG 없는 장대 2~3개 = 가짜 → 대기 |
| 3. 유동성 | 하위TF(1m~15m)에서 동일 저점·스윙·추세선 유동성 스윕(리테일 매수자 손절, 매도자 유인) |
| 4. HTF 캔들 | 상위TF 캔들 몸통이 POI 너머로 마감하지 않음(꼬리만) |
| 5. displacement | 2-7 정의 충족 |
| 6. MSS | displacement 레그가 하위TF 왼쪽 첫 스윙을 몸통 돌파 |
| 7. 진입 | 되돌림이 displacement 레그의 FVG(또는 OB/VI)를 탭할 때 |
| SL | 마지막 방어선 = 스윕한 극점 너머(또는 HTF POI 너머) |
| TP | 1차: 반대편 첫 유동성(부분익절 + SL 본절, 10강). 최종: 상위TF BOS/ERL, 30m 기준이면 30m BOS(6강) |

### ★ S3. 전일 고/저 스윕 (5·9강)
| 상황 | 방향 / 목표 |
|---|---|
| 상승추세 + PDL 스윕 | 매수 / **전일 고점**(또는 그 위 동일 고점) |
| 상승추세 + PDH 스윕 | 카운터 매도 / 아래 **마지막 미탭 POI**까지만 → 거기서 다시 매수 |
| 하락추세 + PDH 스윕 | 매도 / 전일 저점 |
| 하락추세 + PDL 스윕 | 카운터 매수 / 위 미탭 POI까지만 |

- 트리거(1m/5m): 스윕 후 **왼쪽 첫 스윙을 IDM이 아니라 CHoCH(MSS)로 간주**한다. 그 돌파 후 FVG 붙은 OB(인사이드바 묶음 포함) 리테스트에서 진입한다. FVG가 불명확하면 새 구조가 깨끗한 FVG를 만들 때까지 대기한다.
- SL: OB 아래(첫 방어선) 또는 스윙 아래(마지막 방어선).
- 추세 정의는 B1~B2 바이어스를 쓴다.
- PWH/PWL에도 같은 규칙을 적용한다(9강).

### S4. 딜링 레인지 디스카운트 매수 / 프리미엄 매도 (9강)
- B4로 레인지를 확정한다.
- 디스카운트 안 **'마지막' PD 배열**(VI, BPR, OB)이 탭될 때 진입한다. 15m 거부가 없으면 진입하지 않는다.
- displacement 이후 그 레그의 VI/OB/BPR 재탭마다 추가 진입한다.
- SL은 레인지 저점(상승), TP는 레인지 고점.
- 월 목표가 이미 끝났으면 TP를 보수적으로(직전 고점) 잡는다.

### S5. 프랙탈 풀백 (11강)
1. 일봉 POI 탭.
2. **1H MSS + displacement**.
3. 4H POI(풀백 구역)까지 되돌림을 기다린다. **MSS 직후 진입 금지.**
4. MSS 레그의 **마지막 OB**를 리테스트할 때 진입한다. 그 OB는 디스카운트에 있고 앞에 유동성이 있어야 한다. 5m/1m로 리파인한다.
5. SL은 OB 너머, TP는 일봉 목표(ERL).
- 풀백인가 반전인가 = 상위TF에 미탭 POI가 남아 있는가로 판단한다. 남아 있으면 풀백이다.
- 풀백 끝점(상위TF POI)을 특정 못 하면 이 전략은 쓰지 않는다.

### S6. 구조 스윕 진입 (5·6·8강)
| 유형 | 조건 | SL / TP |
|---|---|---|
| ITH/BOS 스윕 반전 | 바이어스 반대쪽 극점을 꼬리로 쓸고 몸통 마감 실패 | 스윕 캔들 너머 (몸통 돌파 마감 시 청산) / 첫 FVG → 반복 스윕 시 동일 고/저 |
| ITL/CHoCH 스윕 지속 | 극단 OB를 건너뛰고 지지 레벨만 꼬리 스윕 후 복귀 (아래 OB/FVG가 없을 때 주로 발생) | 스윕 극점 너머 / ITH·BOS |

- 강의의 확률 서술: 1·5m 80%, 15m~1H 95%+. 상위TF일수록 신뢰도가 높다.

### S7. 블록 컨플루언스 진입 (7강) — 단독 전략이 아니라 S1~S5의 '진입 구역' 후보
- 미티게이션 + FVG(+OB), 브레이커 + FVG, Advanced OB 꼬리-FVG 겹침, 리젝션 MT.
- 리젝션은 **주변 OB/FVG가 모두 채워졌거나 없을 때**만 쓴다.
- 리클레임: 상위TF POI에서 MSS 이후, 진입 레그 왼쪽 스윙 블록을 순차 재탭할 때마다 진입한다.

### S8. 세션 전략 (10강) — 포렉스·금 기준이므로 BTC는 검증 후 채택
| 전략 | 규칙 |
|---|---|
| 아시안 진입 | KST 04:30–09:00 구간의 POI·스윙 고저를 표시 → 아시안 킬존(09–13)이 탭·스윕 후 반전하면 진입(1m MSS는 더블 컨펌). SL = POI 너머. TP = 15m POI·유동성 1/2/3, **유동성 1에서 부분익절 + 본절**, 다음 레벨에서 SL을 중간으로. 바이어스 반대면 가까운 유동성만 TP |
| CBDR | KST 03–09 고저 박스(좁을수록 유효, `[미정의]` 폭 상한). 조건: HTF 미탭 POI + 런던/뉴욕이 **바이어스 반대쪽 아시안 극점 스윕** + displacement. 진입 = 15m FVG/OB 리테스트. SL = 스윕 고점 위. TP = 박스 1~2 SD(뉴스 시 4 SD), 아시안 반대 극점 |
| OTE | 깨끗한 단일 레그(몸통 기준) 또는 세션 레인지의 0.62~0.79 + 1m 거부. SL = 레그 시작점 너머. TP = 0 → -0.27/-0.62/-1. 0.5 아래 FVG/OB가 겹치면 더 일찍 진입 가능. **세션 시작 직후 유다 스윙에서는 금지** |

### S9. 시간순환 스파이크 (11강) — 정성적 요소 많음, 마지막 순위
- TF 사다리 1m → 3m → 5m → 15m → 30m → 1H → 4H.
- 어떤 TF가 자기 FVG/OB를 1~2회 탭한 뒤 **같은 캔들에서 거부**하면 진입한다. 조건은 바로 위 TF에 아직 해당 방향 POI가 없는 것.
- TP는 **바로 위 TF의 POI**다(5m 스파이크 → 15m POI). RR 1:3~1:5.
- 4H 풀백·지속 구역에서 알고리즘을 리셋한다.
- 위 TF에 POI가 '없다'는 판정은 2-4의 PD 배열 탐지로 대신한다.

## 5. 매매 운영 규칙 (강의 언급분)
- **매매 빈도**: 명확한 셋업일 때만 한다. "주 2회, 월 3~4회라도 큰 것을"(6·8강). "매일 매매하면 언젠가 데인다." 강의는 일 최대 횟수 수치를 주지 않았다 `[미정의]`.
- **일봉 POI 도달 직후 1~3일**은 연료 축적 구간이므로 매매를 쉰다(6강).
- **부분익절**: 첫 유동성에서 일부 청산 + SL 본절(10강).
- **역추세(카운터)**는 목표를 짧게, 다음 POI까지만(5·7강).
- **평가 기준**: 최소 14~20회 매매로 평가한다(10강).
- **리스크**: 강사는 펀딩 계좌(일 손실 5%, 전체 10% 한도) 환경을 언급했을 뿐, 포지션 사이징 규칙은 강의에 없다 `[미정의]`.

## 6. 구현 구조 (신규 모듈안, 기존 코드와 독립)

```
smc_btc/
  data.py          # 1m 원천 → 3m/5m/15m/30m/1H/4H/D/W/M 리샘플, UTC 일봉 경계
  candles.py       # 인사이드바 병합, 몸통/꼬리, 종가 돌파 판정
  swings.py        # 3캔들 스윙, ITH/ITL/STH/STL (확정 시점 포함, 미래참조 금지)
  pd_arrays.py     # FVG, VI, BPR, OB, Advanced OB(+MT, 꼬리-FVG 겹침), 충전 여부 추적
  blocks.py        # Mitigation, Breaker, Rejection, Reclaimed
  liquidity.py     # PDH/PDL, PWH/PWL, 월 고저, 동일 고/저, 스윕 이벤트
  displacement.py  # 레그 FVG 개수·범위 판정, 가짜 레그, 인듀스먼트
  bias.py          # B1~B7 → {방향, 목표 목록, 장애물, 무효 레벨}
  sessions.py      # 킬존·CBDR·아시안 구간 (DST 자동)
  entry_module.py  # 0-3 공통 트리거: 스윕→displacement→MSS→리테스트
  strategies/      # S1~S9 각각: 신호 = {진입가, SL, TP1/TP2, 근거 태그}
  backtest.py      # 완결봉만, 다음 봉 시가 체결, 수수료·슬리피지, SL 우선
```

**검증 원칙** (지난 과적합·미래누수 교훈):
- 스윙·ITH/ITL은 **확정 봉 이후부터만** 사용한다.
- 상위TF 값은 **완결된 상위봉만** 하위TF에 노출한다.
- 수수료(taker 0.06%×2) + 슬리피지를 넣는다.
- 각 `[미정의]` 파라미터는 IS/OOS로 나눠 고르고, 강의 기본값과 비교한다.
