## 0. 공통 토대 — 모든 전략의 전제

### 0-1. 바이어스(방향): 없으면 매매하지 않는다
분석 순서는 **월 → 주 → 일 → 4H/1H → 15m 이하**다. 하위TF에서 시작해 위로 올라가면 방향을 틀린다(9강).

1. **봉 내부 패턴**(9강): 하락 봉은 O→H→L→C(먼저 가짜 상승), 상승 봉은 O→L→H→C(먼저 가짜 하락)로 움직인다.
   - 상승 바이어스면 **해당 월·주·일봉 시가 아래에서만 매수**한다. 하락이면 시가 위에서만 매도한다.
2. **월봉 바이어스**: 월봉 POI 탭과 displacement를 보고 다음 달 방향과 목표를 정한다. 그 달 동안 반대 방향 매매는 찾지 않는다.
   - 단, 그 사이 일봉·주봉 장애물(OB, VI, 리젝션)에서는 임시 되돌림이 온다.
3. **데일리 바이어스**:
   - 전일 저점을 스윕하고 위로 마감하면 → 다음 날 오늘 고점이 목표다. 반대 경우도 대칭이다.
   - 스윕 없이 전일 고점 위로 종가 마감하면(지속형) → 다음 날도 같은 방향이다.
   - 바이어스 반대 방향 신호는 약하다. 가까운 POI만 탭하고 돌아온다.
4. **딜링 레인지**: 양쪽 유동성을 모두 사냥한 레그를 말한다. 그 레그의 디스카운트에서 매수하고 레인지 고점을 목표로 한다(2~4주 바이어스).
5. **내러티브와 3B**(10강): 최근 유동성 스윕이나 PD 배열 탭 → 반대 방향 첫 대상 → 프리미엄/디스카운트 순서로 본다.
6. **프랙탈 위계**(11강):
   - 상위TF에 미탭 POI가 남아 있으면 하위TF 역행은 풀백일 뿐이다.
   - 각 TF는 자기 목표를 끝낸 뒤 트랩을 만든다.
7. **바이어스 오판 신호**:
   - 상승 바이어스인데 상위TF(1H/4H) ITL이 깨지면 방향을 잘못 본 것이다(8·11강).
   - 4H/일봉 3캔들 스윙이 깨지는 것도 같은 신호다.

### 0-2. 공통 필터

| 필터 | 규칙 |
|---|---|
| 프리미엄/디스카운트 | 매수는 레그·레인지의 0.5 아래 PD 배열에서만, 매도는 0.5 위에서만 |
| 유동성 | **유동성 없는 POI는 깨진다.** POI 앞에 하위TF 스윙·동일고저·추세선이 있어야 한다. 가격은 IRL을 먼저 가져간 뒤 ERL로 간다 |
| displacement | **필수 조건이다.** 상위TF POI 도달 후 처음 나오는 FVG 없는 장대 2~3개는 가짜(진입 금지). FVG가 연달아 생기는 레그가 진짜다 |
| 구조 깨짐 판정 | BOS/CHoCH는 몸통 종가 마감만 인정한다. 꼬리만 넘으면 유동성 스윕이다 |
| OB 유효 조건 | 기본 OB는 FVG가 붙어 있어야 한다. FVG 없는 Advanced OB는 50%(MT) 또는 꼬리-FVG 겹침 구간을 쓴다 |
| 겹침 | 여러 PD 배열(OB+FVG+VI+BPR+미티게이션)이 겹칠수록 확률이 높아진다 |
| 맥락 | 어떤 블록이든 **상위TF 맥락**(PDH/PDL 스윕, 상위TF POI, 극단 POI)이 없으면 실패한다 |
| 인듀스먼트 | 바이어스 반대 방향으로 힘없이 겹치는 캔들로 만든 구조, 그 안의 OB는 함정이다 |
| 세션 | 킬존(뉴욕시간): Asian 20–24 / London 02–05 / NY 07–10 / LC 10–12. 런던클로즈 이후 매매 안 함. 세션 시작 직후 유다 스윙 주의 |

### 0-3. 진입 컨펌 공통 패턴 (6·11강의 '진입 모듈')
1. 상위TF POI에 도달한다.
2. 하위TF에서 유동성 스윕과 함께 가짜 레그로 리테일을 가둔다.
3. **displacement**가 나온다(FVG 연속, 1m 캔들 하나가 평소 5m 캔들보다 큼).
4. 상위TF 캔들 몸통은 POI 너머로 마감하지 않는다(꼬리만).
5. displacement 레그가 **MSS**(첫 스윙 몸통 돌파)를 만든다.
6. 되돌림이 그 레그의 FVG/OB를 재탭하면 진입한다.
7. SL은 마지막 방어선(스윕 극점 또는 상위TF POI 너머)이다. TP는 상위TF BOS 또는 반대편 유동성이다.

## 1. 추세 지속형

### A. IDM 스윕 / IDM 아래 첫 OB / 극단 OB (3·4·6강)
| 항목 | 내용 |
|---|---|
| 개념 | HH는 IDM(HH 왼쪽 첫 유효 내부스윙)이 쓸려야 확정된다. HL은 다음 BOS로 확정된다. 진입은 IDM 이후에만 한다 |
| POI 1: IDM 스윕 | 되돌림이 IDM을 꼬리로 쓸고 IDM 위로 마감할 때. IDM 아래 미탭 OB/FVG가 없으면 95%+, 많으면 50%(비추). 30m 캔들이 스윕하고 그 안 1m에 CHoCH+FVG가 있으면 ~90% |
| POI 2: IDM 아래 첫 OB(디맨드) | 몸통이 IDM 아래로 마감하면 POI 1은 무효가 된다. 첫 OB 탭+꼬리 거부에서 진입한다. ≥80% |
| POI 3: 극단 OB | 첫 OB가 깨지면 중간 OB는 전부 건너뛰고 **CHoCH(HL) 바로 앞 마지막 OB**를 쓴다. ~90% |
| SL / TP | OB 너머 / HH·BOS (보수적으로는 HH 바로 아래 첫 FVG) |
| 무효 | HL 몸통 이탈 = CHoCH |

### B. Order Flow (4강)
- 레그의 마지막 반대 풀백 중 **아직 탭되지 않은 구간**으로 돌아올 때 진입한다.
- SL은 오더플로 너머, TP는 다음 BOS다.

### C. Refined OB (4·7강) — 실행 기법
- 상위TF OB가 넓으면 그 안을 15m→5m→1m로 내려가 FVG가 붙은 작은 OB에서 진입한다.
- SL이 1/4~1/5로 줄어든다.

### D. 미티게이션 블록 (7강)
| 항목 | 내용 |
|---|---|
| 조건 | 스윙 실패: 상승에서 HH는 깨지는데 HL은 못 깬다 |
| 진입 | 몸통으로 깨져 넘어간 직전 HH의 마지막 음봉(스윙 최고점 캔들)에 되돌아오면 매수. 하락은 대칭 |
| 단독 금지 | FVG/OB와 겹칠 때만 쓴다. 예: 전일 고점 스윕 → 하락 바이어스 → 미티게이션+FVG(+OB) 매도 |

### E. ITH/ITL 레인지 매매 (8강) — 24시간 시장 권장 매핑
| 항목 | 내용 |
|---|---|
| 정의 | ITH = 가운데 3캔들 스윙 고점이고, 좌우에 더 낮은 3캔들 스윙 고점이 하나씩 있는 것. ITL은 대칭 |
| 규칙 | 상승 바이어스인 동안 **ITH는 계속 깨지고 ITL은 안 깨진다.** ITL 이후 STL도 ITH가 깨질 때까지 안 깨진다(트레일링 SL 기준) |
| 진입 | ITL 확정 후 ITH~ITL 디스카운트의 PD 배열(FVG/BPR/미티게이션/Advanced OB의 MT). POI가 없으면 ITL 꼬리 스윕 |
| SL / TP | ITL 아래(버퍼, 몸통 마감 시 손절) / ITH |
| 프랙탈 매핑 | **구조는 상위TF(1H)에서만 찍는다.** 상위TF STL = 하위TF의 유효 ITL이다. 그 사이 하위TF ITH/ITL은 트랩이다 |

### F. 4H/일봉 3캔들 스윙 지속 (8강)
- 상위TF POI에서 3캔들 스윙이 생기면 방향 전환이 컨펌된다.
- 다음 미탭 POI까지 직전 3캔들 스윙은 깨지지 않는다(꼬리 스윕은 가능).
- 4H 캔들이 완성되기 전에 15m로 내려가 그 저점 형성 구간의 겹친 PD 배열에서 진입한다. 목표는 4H 고점이다.

### G. 프랙탈 풀백 진입 (11강)
- 순서: 일봉 POI 탭 → **1H 이상에서 MSS** + displacement → 4H POI까지 풀백 대기.
- MSS 직후에는 진입하지 않는다. MSS 레그의 마지막 OB(디스카운트, 유동성 동반) 리테스트에서 진입한다.
- 하위TF로 리파인해서 들어가고, SL은 OB 너머, TP는 일봉 목표(ERL)다.
- 풀백 끝점을 모르면 풀백 매매는 금지다.

## 2. 유동성 스윕·반전형

### H. 전일 고/저(PDH/PDL) 스윕 (5강)
| 상황 | 목표 |
|---|---|
| 상승추세 + PDL 스윕 | **전일 고점**(또는 동일고점), 큰 목표 |
| 상승추세 + PDH 스윕 | 아래 마지막 미탭 POI까지만(카운터, 작게, 예 1:4). 그 뒤 다시 매수 |
| 하락추세 + PDH 스윕 | 전일 저점 |
| 하락추세 + PDL 스윕 | 위 미탭 POI까지만 |

- 컨펌(1m/5m): 반전 진입이므로 스윕 후 **왼쪽 첫 스윙을 IDM이 아니라 CHoCH(MSS)로 본다.** CHoCH 후 FVG 붙은 OB(인사이드바 묶음 포함) 리테스트에서 진입한다.
- SL은 OB 아래(또는 스윙 아래), TP는 위 표대로다. 강사 사례 RR은 1:30~1:90이다.

### I. 스윕 → displacement → 리테스트 (11강) — 가장 기계적
| 항목 | 내용 |
|---|---|
| 시그널 | 바이어스 반대편 동일 저점·스윙·추세선 유동성 스윕 |
| 컨펌 | 스윕 직후 FVG를 만드는 displacement. 없으면 더 깊은 유동성을 가져갈 때까지 대기 |
| 진입 | displacement가 만든 OB/FVG 리테스트 |
| SL / TP | 스윕 극점 너머 / 반대편 ERL 또는 상위TF POI |

### J. BOS / CHoCH 스윕 (5·6강)
- **BOS 스윕**: BOS 레벨을 꼬리로 쓸고 몸통 마감에 실패하면 반대 방향으로 간다.
  - SL은 스윕 캔들 너머(매우 작게)이고, 몸통이 BOS 너머로 마감하면 청산한다.
  - TP는 1차 첫 FVG, 반복 스윕이면 동일고/저다. 확률은 1·5m 80%, 15m~1H 95%+.
- **CHoCH 스윕**: 극단 OB가 무시되고 CHoCH 레벨만 꼬리로 뚫고 복귀하면 추세가 지속된다. TP는 BOS이고 확률 ~90%. 주로 IDM 아래에 OB/FVG가 없을 때 나온다.

### K. CHoCH 이후 첫 되돌림 → 본 추세 (5강)
1. 상승추세에서 CHoCH가 나와도 바로 매도하지 않는다. **먼저 매수 되돌림이 온다.**
2. 되돌림 목표는 CHoCH 지점 위, 왼쪽 과거 구조의 **가장 가까운 첫 OB**다.
3. 하위TF CHoCH-리테스트로 카운터 매수를 하고, 첫 OB에 도달하면 하락 추세 진입(LL→IDM→OB 매도, TP = BOS)으로 전환한다.

### L. 브레이커 블록 (7강)
- **양쪽 유동성을 다 가져간 뒤**의 반전 블록이다.
  - 하락: 고점(BSL) 스윕 → 저점(SSL) 이탈 → 되돌아와 그 고점 스윙 블록 탭 → 매도.
  - 상승은 대칭이다.
- 스윙 내부 캔들이 전부 같은 색이면 50%(MT)를 쓴다.
- 예: PDH 스윕 + displacement + MSS + 브레이커(+FVG). SL은 블록 위, **TP는 전일 저점**이다.

### M. 리클레임 OB — 마켓메이커 모델 기초 (7강)
- 상위TF POI로 향하는 느린 레그 동안 OB가 쌓인다.
- POI에 도달하면 displacement + MSS가 나온다. 이후 진입 레그 왼쪽 스윙들의 OB를 차례로 재탭할 때마다 진입한다.
  - 위에서 꺾일 때는 스윙 고점의 마지막 양봉, 아래서 꺾일 때는 스윙 저점의 마지막 음봉이다.

### N. 리젝션 블록 (7강)
- 스윙 극점의 긴 꼬리 구간 50%에서 진입한다.
- 하위TF는 꼬리 2개 이상, 30m 이상은 1개로 충분하다.
- **MT 너머 몸통 마감이면 함정(90% 실패)이다.**
- 주변 OB/FVG가 모두 채워졌거나 없고, PDH/PDL 같은 유동성 맥락이 있을 때만 쓴다. SL은 매우 작다.

## 3. 시간·세션형 (포렉스·금 기준 설명)

### O. 아시안 진입 (뉴욕시간 15:30~20:00 구간 표시) (10강)
1. 그 구간의 POI나 스윙 고저를 표시한다.
2. 아시안 세션이 그것을 탭·스윕하고 반전하면 진입한다(1m MSS는 더블 컨펌).
3. SL은 POI 너머다. TP는 15m POI·유동성 1/2/3이다. **유동성 1에서 부분익절하고 SL을 본절로 옮긴다.**
4. 바이어스 반대 방향이면 가까운 TP만 잡는다.

### P. CBDR (10강)
- 뉴욕 14:00~20:00 박스를 그린다. 좁을수록 유효하다.
- 조건: 상위TF 미탭 POI가 있고, 런던/뉴욕이 **바이어스 반대쪽 아시안 극점을 스윕**하고, displacement가 나온다.
- 15m FVG/OB 리테스트에서 진입한다. SL은 스윕 고점 위, TP는 박스 1~2 SD(뉴스 시 4 SD)다.

### Q. OTE (10강)
| 항목 | 내용 |
|---|---|
| 레그 | 깨끗한 단일 레그(몸통 기준) 또는 세션 레인지 |
| 진입 | 0.62~0.79 구간 + 1m 거부. 0.5 아래에 FVG/OB가 겹치면 더 일찍 진입 가능 |
| SL / TP | 레그 시작점 너머 / 0, -0.27, -0.62, -1 |
| 조건 | 일봉 바이어스 확정 + 4H/1H 마지막 POI가 남아 있음 |

### R. 시간순환 스파이크 (11강)
- 각 TF는 자기 FVG/OB를 탭한 직후 달려서 바로 위 TF에 POI를 만든다(1m→5m→15m→30m→1H→4H).
- 같은 캔들에서 거부가 나오면 진입한다.
- **TP는 스파이크 TF의 바로 위 TF POI**다(RR 1:3~1:5). 4H 풀백·지속 구역에서 리셋한다.

### S. STL/STH 이탈 되돌림 (11강)
- 상승 구조에서 1H/4H STL이 깨지면 STL~ITL 사이 POI까지 하락할 수 있다.
- 위쪽 FVG에서 매도하고, SL은 15m ITH(=1H STH) 위, TP는 아래 POI다.
- 그 POI가 탭된 뒤에는 매도하지 않는다(바이어스는 여전히 상방).

## 4. 봇 적용 관점 (검증 전, 실거래 반영 안 함)

11편 전체에서 반복되는 성공 조건은 **'상위TF 바이어스 + 유동성 스윕 + displacement + 겹친 PD 배열'**이다. 단일 TF 패턴만으로는 50% 확률게임이라고 강사가 계속 말한다.

이는 지난 백테스트 결과와 같은 방향이다(`research/단기수익_탐색_2026-10-01.md`). 15m 단일 TF OTE/MTF/킬존은 수수료를 반영하자 전부 마이너스였다.

코드로 옮기기 쉬운 순서:

1. **바이어스 레이어(9강)**: 월·주·일봉 시가 대비 위치 + 전일 고저 스윕/종가 규칙.
   - OHLC만으로 계산되므로 기계화가 가장 쉽다.
   - 기존 일봉+4H 추세전략의 방향 필터로 붙일 수 있다.
2. **I. 스윕→displacement→리테스트**, **H. PDH/PDL 스윕 + 하위TF CHoCH**: 규칙이 명확하다.
3. **E. ITH/ITL (1H 매핑 → 15m 실행)**: 강사가 24시간 시장용으로 권장한 매핑이다. 3캔들 스윙 정의가 명확하다.
4. 공통 필터: OB+FVG 필수, 프리미엄/디스카운트, POI 앞 유동성 존재, displacement(FVG 연속) 검사.

세션형(O·P)은 포렉스·금 기준이다. 24시간 크립토에서는 세션 효과를 별도로 검증해야 한다.

이 중 무엇을 engine_v2(정직한 백테스트)로 검증할지 정해 주시면 진행한다.
