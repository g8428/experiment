# 7강 노트 — 블록 5종 (Advanced OB · Mitigation · Breaker · Rejection · Reclaimed) — 전체 94줄 100% 읽음
※ 강사 표현으로 7강부터 '고급 SMC = ICT' 시작. **공통 대원칙: 어떤 블록이든 '상위TF 맥락'(전일 고/저 스윕, 상위TF POI, 극단 POI) 없이 쓰면 실패. 블록은 그 맥락 위의 실행 도구.**

## 준비: 프리미엄/디스카운트 (피보 0 / 0.5 / 1만 표시)
- 레그 저→고: 0.5 위 = 프리미엄, 아래 = 디스카운트, 0.5 = 균형(equilibrium, 여기서 반등하기도).
- 상승 바이어스면 디스카운트에서만 매수(목표 프리미엄), 하락이면 프리미엄에서만 매도. 바이어스 반대면 작동 안 함.

## 1. Advanced OB (FVG 없는 OB)
- 매도하려면 **마지막 매수 캔들 묶음**(연속 양봉 전체, 저점~고점), 매수하려면 마지막 음봉 묶음. 1개~5개 가능. 중간에 반대색이 끼면 끊어서 최근 묶음만(인사이드바면 묶어서 하나로).
- 진입 위치 규칙:
  - 기본: OB의 **50%(Mean Threshold, MT)**. MT 너머로 몸통 마감하면 확률 급락(무효).
  - **OB의 꼬리가 인접 미충전 FVG와 겹치면(Overlap)** → MT까지 안 옴. **그 꼬리+FVG 구간**에서 진입(더 얕게). FVG가 이미 채워졌으면 OB 전체/MT 사용.
- 프랙탈: 5m에서 IDM이 안 보이면 1m로 내려가 IDM·OB를 찾음(=Refined OB). 5m의 Advanced OB가 1m에선 FVG+OB로 보임.
- 예시 SL = OB 고점 위, TP = BOS(또는 바이어스 목표).

## 2. Mitigation Block (추세 지속형)
- 조건: **스윙 실패(Swing Failure)** — 상승에서 HH는 깨지는데 HL(이전 저점)은 못 깸 → 상승 지속. 이때 깨져 넘어간 직전 HH의 **마지막 음봉(=실패한 공급 OB, 스윙 최고점 캔들)** 으로 되돌아오면 매수. 하락은 반대(LL 깨고 LH 못 깸 → 깨진 LL의 마지막 양봉으로 되돌아오면 매도).
- 깨는 캔들은 **OB 너머 몸통 마감** 필수.
- 논리: 그 자리에서 물린 반대 포지션이 본전 탈출하며 유동성 발생.
- **단독 사용 금지 — FVG/OB와 겹칠 때만(이중·삼중 컨펌)**. 예: 전일 고점 스윕 → 하락 바이어스 → 미티게이션 블록+FVG(+OB)에서 매도.

## 3. Breaker Block (반전 후 첫 블록)
- 미티게이션과 모양 비슷, 차이 = **양쪽 유동성을 모두 가져감**.
  - 하락 브레이커: 직전 스윙 고점(BSL)을 먼저 쓸고 → 저점(SSL)을 깸 → 되돌아와 그 고점 스윙의 블록(마지막 양봉)을 탭 → 하락.
  - 상승 브레이커: 저점(SSL) 먼저 쓸고 → 고점(BSL) 깸 → 되돌아와 탭 → 상승.
- 이후 같은 방향으로 이어지는 블록들은 미티게이션.
- 스윙 내부 캔들이 전부 같은 색이면 그 구간 50%(MT)를 사용.
- 예: 전일 고점 스윕 + displacement + MSS + 브레이커(+FVG 겹침) → 매도, SL 브레이커 위(또는 마지막 FVG 위), **TP = 전일 저점**.

## 4. Rejection Block (꼬리 블록)
- 스윙 고점(하락)/저점(상승)에 생긴 **긴 꼬리들**. 하위TF(1~3m)는 **꼬리 2개 이상**, 30m 이상은 1개로 충분.
- 진입 = 꼬리 구간의 **50%(MT)**. **MT 너머 몸통 마감 → 함정(90% 실패)**; 안 넘으면 고확률.
- SL 매우 작음. **사용 조건: 주변 OB/FVG가 모두 채워졌거나 없고, 전일 고/저 같은 유동성 맥락이 있을 때.**
- 하위TF가 먼저 추세 전환 신호를 줌(상위TF 전환 전 1m→3m→5m…). 역추세(카운터) 리젝션은 TP 작게(다음 OB까지).

## 5. Reclaimed OB (마켓메이커 매수/매도 모델 기초)
- 상위TF POI(30m/1H/4H/D)로 가는 느린 레그 동안 큰손이 미리 반대 주문을 쌓아 OB들이 생김 → POI 도달 → **displacement + MSS** → 반대 방향으로 가며 **진입 레그(왼쪽) 스윙들의 OB를 차례로 재탭**.
  - 위에서 꺾여 하락할 땐 **왼쪽 스윙 고점의 마지막 양봉**들, 아래서 꺾여 상승할 땐 **왼쪽 스윙 저점의 마지막 음봉**들.
- 각 블록은 직전 스윙 너머 몸통 마감 후 차례로 활성화. 블록 꼬리가 50% 이상이면 리젝션 블록 방식(꼬리 MT)으로.
- 예(5m): 극단 POI 탭 → MSS → 리클레임 OB 4개 연속 매수, SL 각 블록 아래, TP = 위쪽 유동성/FVG.
- 진입 레그가 느리고 겹치는 캔들(유동성 생성) → POI에서 급반전이 전형.
