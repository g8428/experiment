# 전략별 분석 v1 — 주기 × 종목

> 주기 = 보유시간 기준. 스캘핑 <1h · 데이 1h\~1d · 스윙 1\~7d · 장투 >7d.
> 봉 기반 지표(익절/손절%, MFE/MAE, 물타기, 역추세, 첫축소)는 XBTUSD·ETHUSD만. 표 원본 `quant-data/aoa/strategy_by_cell_*.csv`.

XBTUSD는 전 주기 흑자이고 건수의 81%를 차지하는 주력. 어느 주기든 승률 63\~79%로 균질.

## 6. 주기 전환의 논리

| | 스캘핑 → 데이 | 데이 → 스윙 | 스윙 → 장투 |
|---|---|---|---|
| 승률 | 79 → 74 | 74 → 63 | 63 → 61 |
| 손익비 | 0.62 → 0.60 | 0.60 → **1.11** | 1.11 → 0.96 |
| 물타기 | 23 → **66%** | 66 → 65 | 65 → 51\~76 |
| capture | 0.69 → 0.38 | 0.38 → 0.20 | 0.20 → 0.15 |
| 첫 축소 | 92 → 31% | 31 → 11% | 11 → 4% |
| MAE −10% 초과 | 0 → 15건 | 15 → 18 | 18 → 13 |

**한 축으로 읽으면**: 주기가 길어질수록 진입 후 곧바로 덜어내기 시작하고(92→4%), 최대 유리폭 중 실현하는 비율은 줄며(0.69→0.15), 대신 건당 절대액과 손익비가 커진다. 승률은 79→61로 떨어지지만 손익분기(63.6%)는 장투에서도 아슬아슬하게 넘긴다.

**꼬리는 데이부터 붙는다.** 스캘핑엔 −10% 역행이 0건, 데이부터 15건. 물타기가 23%→66%로 뛰는 지점과 일치한다 — **물타기가 꼬리를 만든다**(역행에 평단을 낮추며 버티니 역행이 깊어질 수 있다).
