## 0. 요약

같은 원본(BitMEX aoa 공개 체결 로그)을 쓰고 **크기 통계는 거의 일치**한다. 그런데 핵심 해석 3개가 정반대이고, 그 3개가 그대로 "자동매매 규칙"으로 들어갔다.

원인은 하나로 수렴한다 — **그쪽은 방향(sign) 통계를 재지 않았다.** 체결 수·보유시간·사이즈 분위 같은 크기만 보면 "체결 363회 = 피라미딩", "큰 사이즈 = 확신"이라는 상식적 해석으로 미끄러진다. 추가진입이 평단보다 유리한 쪽인지 불리한 쪽인지, 청산이 최악점 대비 어디인지를 재야 뒤집힌다.

## 2. 정반대인 것 3개

### ① "초기 소량 진입 + 방향 맞으면 피라미딩" → 실제는 물타기

| | |
|---|---|
| 그쪽 근거 | "XBTUSD 라운드트립당 평균 363회 체결" |
| 그쪽 해석 | 작게 시작해 **맞다는 신호가 나올 때 추가** |
| 우리 실측 | 추가진입 626,797건 중 **59%가 물타기**(롱인데 더 싸게 / 숏인데 더 비싸게). 수량가중 59.4%. 4년 내내 58\~65% |
| 판정 | **반대.** 맞을 때 더 넣는 게 아니라 **틀릴 때 더 넣는다** |

체결 횟수는 분할의 크기만 알려줄 뿐 **분할의 방향**을 알려주지 않는다. 그 방향을 재려면 각 추가진입 시점의 직전 평단을 복원해야 한다.

### ② "포지션 규모는 확신에 비례" → 실제는 역행의 산물

| | |
|---|---|
| 그쪽 근거 | "상위 20% 사이즈가 승률 최저(66.6%)인데 이익 57%" |
| 그쪽 해석 | 확신이 큰 방향에 사이즈를 실어라 |
| 우리 실측 | 같은 현상. 단 **사이즈 4분위 승률 78.4 → 77.0 → 73.5 → 65.8%**, 실현% 중앙 +0.50 → +0.23%. 사이즈를 무작위 재배정하면 **97\~99.8%의 경우 더 벌었다**(Σ실현%×사이즈 실제 372 vs 셔플 중앙 642) |
| 판정 | **반대.** 큰 포지션은 확신이 커서가 아니라 **물타기로 역행할수록 커진 것**. 사이징은 기여가 아니라 **마이너스** |

양쪽이 같은 숫자를 봤는데 해석이 갈렸다. "큰 사이즈가 이익의 57%"는 **큰 사이즈가 좋다**가 아니라 **큰 사이즈가 금액을 좌우한다**는 뜻일 뿐이고, 단위당 성과(승률·실현%)로 보면 최악이다. ①(물타기)을 재야 왜 그런지가 나온다.

### ③ "트레일링 스탑 + 자산 1\~2% 하드스탑" → 그는 스탑을 폐기했다

| | |
|---|---|
| 그쪽 근거 | "MDD −14.4%는 절제된 수준" → 하드스탑 모듈 권장 |
| 우리 실측 | Stop/StopLimit 축소체결 **4,435건이 전부 마이너스**(양수 0건), 누적 **−109.7 BTC**. 손실의 76%가 2020-06·09 두 달에 집중되자 **2020-09-08 이후 15개월 0건**. 대신 분할청산 극단화(에피소드당 축소체결 중앙 10 → 726) |
| 판정 | **반대.** −14.4% 낙폭은 스탑이 만든 게 아니라 **레버리지 1배대 + 반등에 덜어내기**(손절 바닥비율 0.28, 68%가 최악점에서 절반 이상 회복 후 정리)가 만든 것 |

여기에 1\~2% 하드스탑을 넣으면 그의 스타일이 아니라 **그가 2020년에 −110 BTC 내고 버린 스타일**이 된다. → 정량 검증은 분석_I_가상손절.

### (부가) "방향 무관 모멘텀/오더플로우 신호"
롱/숏 대칭은 맞다. 그런데 그 신호는 모멘텀이 아니다 — **추격 돌파 진입 1.6% vs 역방향 돌파 9.4%**(6배). 역추세다.

## 3. 기술적 차이

| | 타 분석 | 우리 |
|---|---|---|
| 손익 재구성 | `homenotional` 텔레스코핑 합산 + ETHUSD 선형 배수 수동 적용 | **`execcost`** 그대로 (정산통화 XBt 정수단위 부호 있는 체결금액) |
| 원장 대비 오차 | **3\~10%** (본인 명시) | **심볼 45/46개 소수점 8자리 일치**, 잔고 오차 0.000000 BTC |
| 시각 정밀도 | "타임스탬프 손상 → **일 단위**만 가능" | **마이크로초** |
| 봉 기반 지표 | 없음 | MFE/MAE·진입 봉내 위치·물타기·바닥비율·점유율 |

**시각 정밀도 주장은 사실과 다르다.** 손상된 건 **지갑 CSV의 timestamp/transacttime**뿐이고(엑셀에 열려 "57:26.3"으로 깨짐), **체결 CSV의 `transacttime`은 마이크로초까지 정상**이다(`2018-03-05 09:16:57.937933`). 지갑 원장은 `date` 컬럼만 쓰면 되고, 체결은 원본 그대로 쓸 수 있다. 이 오판 때문에 그쪽은 봉 단위 지표를 포기했고, 방향 통계가 통째로 빠졌다.

손익 재구성도 마찬가지다. `homenotional`은 당시 환율로 계산된 **파생값**이라 정밀 손익에 부적합하고(우리 A파트에서 별도 확인), `execcost`를 쓰면 계약형태(inverse/quanto/linear)별 공식 분기 자체가 불필요하다 — 부호가 반대여도 `손익 = −(execcost 합)`으로 통일된다. 3\~10% 오차는 여기서 나온 것으로 보인다.

## 4. 그쪽이 나은 것

**프레젠테이션.** 누적 실현손익 곡선에 고점 대비 낙폭 음영, USD 환산 자산가치, 최근 라운드트립 15건 표, 섹션 내러티브 — 읽는 사람 기준으로 잘 짜였다. 우리는 수치는 깊은데 보여주는 방식이 약했다.

→ 그래서 [대시보드] 탭을 만들었다: 그쪽이 가진 차트를 전부 갖추고, 우리만 가진 방향 통계 차트(물타기·MAE/실현% 산점도·바닥비율 분포·사이즈 분위·ATH 구간·점유율·셔플 분포)를 얹었다.

**한계 서술도 정직하다** — "재량적 트레이더의 진입 이유는 체결 로그만으로 복원 불가", "표본 작은 구간 과최적화 위험", "페이퍼트레이딩 먼저". 이건 그대로 동의한다.

## 5. 교훈 (우리 작업에 남길 것)

1. **크기 통계만으로 행동을 추론하지 말 것.** 체결 횟수·사이즈 분위는 "무엇을 했나"를 말해주지 않는다. 방향(유리/불리, 평단 대비, 최악점 대비)을 재야 한다.
2. **"큰 사이즈가 이익의 N%"는 사이징이 좋다는 근거가 아니다.** 단위당 성과(승률·실현%)와 셔플 대조를 같이 봐야 한다.
3. **원장과 1e-8까지 맞추기 전에는 해석하지 말 것.** 3\~10% 오차는 개별 셀 판정을 뒤집을 수 있다.
4. **"데이터가 손상됐다"는 판단을 파일 단위로 내리지 말 것.** 지갑 CSV가 깨졌다고 체결 CSV까지 포기하면 분석의 절반이 날아간다.
