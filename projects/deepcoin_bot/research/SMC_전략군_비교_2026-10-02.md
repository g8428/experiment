# SMC 전략군 비교 백테스트 — 2026-10-02

## 조사 범위

SMC는 단일 진입 신호가 아니므로, 프로젝트에 구현된 구성 요소를 단독 규칙으로 분리해 비교했다.

| 테스트 이름 | 분리한 SMC 아이디어 | 프로젝트 구현 |
|---|---|---|
| `smc_raw` | BOS/ChoCh 또는 유동성 스윕 + OB, 목표는 FVG/스윙 유동성 | `get_smc_signal()` |
| `smc_ote` | 유동성 스윕 후 0.618~0.786 되돌림 진입 | `get_ote_signal()` |
| `smc_mtf` | HTF 방향 + 세션 + OB/FVG 컨플루언스 + 5분봉 확인 | `get_mtf_signal()` |
| `smc_kz` | 뉴욕 세션 + HTF 정렬 + OB/FVG | `get_killzone_signal()` |
| `smc_breaker` | 실패한 OB가 반대 역할로 바뀐 뒤 재시험 | `get_breaker_signal()` |
| `legacy_r2` | 현재 우선순위 OTE→MTF 체인 | 비교 기준 |

GitHub 공개 구현들도 대체로 이 요소들을 조합한다. 예를 들어 [Frosty098/smc-bos-strategy](https://github.com/Frosty098/smc-bos-strategy)는 HTF 방향, 스윕, OB/FVG/Equilibrium 구간, LTF BOS를 조합하고, [frankabingale1111/smc-backtest](https://github.com/frankabingale1111/smc-backtest)는 sweep→FVG/OB 진입과 점수 임계값 테스트를 제공한다. 저장소에 게시된 성과 숫자는 데이터·체결·재현 조건이 독립 검증되지 않아 이번 결론에는 사용하지 않았다.

## 공통 테스트 조건

- Deepcoin 로컬 캔들, 15분봉 실행 및 완결된 상위 시간봉만 사용
- BTC 2024-10-01~2026-10-01, 전체 2년 및 전·후반 1년 분리
- ETH/XRP 2025-10-01~2026-10-01 OOS 구간
- 거래당 계좌 리스크 2%(손절 가격 손실 기준), 레버리지 상한 20배, 편도 수수료 0.06%, 시장가 슬리피지 0.02%
- 다음 봉 시가 체결, 봉 안에서 SL/TP가 모두 닿으면 SL 우선
- 기존 라이브 진입 함수 및 공통 RR/SL/TP 게이트 사용. 일일 손실·거래 수 제한도 동일 적용

수익률은 이 가정하의 계좌 복리 수익률이다. SMC 구조·스윕·OB/FVG는 OHLCV로 판별한 근사치이며 실제 호가 잔량이나 청산 흐름은 포함하지 않았다.

## 판정

**이 버전들의 실거래 전환은 권하지 않는다.** 이번 테스트에서 SMC라는 이름이나 특정 패턴만으로 우위를 얻지 못했다. 특히 원시 SMC 조합은 신호가 너무 많아 계좌를 크게 훼손했고, OTE/세션/Breaker는 비용 차감 후에도 PF가 낮았다. MTF의 작은 BTC OOS 플러스는 거래 수가 적고 타 심볼에서 재현되지 않았다.

이 결과는 SMC 전체를 반증한 것이 아니라, 프로젝트의 현재 기계화 규칙·15분봉 캔들 프록시·수수료 조건을 반증한다. 다음 후보를 검토한다면 OB/FVG의 생성·무효화·재시험 순서를 명시하고, sweep→MSS/BOS 확인→POI 재진입을 한 가지 고정 규칙으로 구현한 뒤 별도 OOS에서 다시 검증해야 한다. 파라미터를 이번 표본에 맞춰 수선하지 않았다.
