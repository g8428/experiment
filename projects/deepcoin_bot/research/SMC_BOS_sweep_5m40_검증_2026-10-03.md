# SMC 구조·스윕 5분봉 40개 제한 검증 — 2026-10-03

## 변경 정의

요청한 “BOC”는 BOS/ChoCh로 해석했다. 신규 연구 옵션에서는 **가장 최근 완결 5분봉 40개(200분)**만 사용해 스윙 후보, BOS/ChoCh 돌파, 스윕을 판정하고 이벤트 검색도 그 40개 전체로 제한한다.

- BOS/ChoCh: 40개 5분봉 안에서 확정된 swing high/low만 구조 레벨로 인정하고, 돌파 종가도 그 창 안에서만 검색
- 스윕: 같은 40개 안의 pivot 레벨만 대상이며, sweep/reclaim 이벤트도 같은 창 안에서만 검색
- 기존 15분봉 OB/FVG 구간, OTE 되돌림 범위, HTF 추세·레짐 필터, SL/TP, 체결 방식은 유지
- 신호는 15분봉 마감 후 판단하고 다음 봉 시가에 진입. 구조용 5분봉은 당시까지 완료된 봉만 사용
- `smc_breaker`는 직접 BOS/스윕 이벤트를 쓰지 않고 실패 OB의 역할 전환을 보므로 변경 대상에서 제외

이 방식은 OB/FVG와 구조 신호를 다른 시간봉에서 가져오는 명시적 혼합형이다. 결과를 기존 15분봉 모델과 비교해 시간봉 혼합의 영향을 본다.

## BTC: 기존 신호 규칙 vs 최근 40개 5분봉 구조

두 결과 모두 BTC 2024-10-01~2026-10-01, 거래당 가격 손절 리스크 2%, 편도 수수료 0.06%, 슬리피지 0.02%, 같은 다음 봉 체결 및 일일 제한을 사용했다.

| 전략 | 기존 15m 거래 / 수익률 | 5m×40 거래 / 수익률 | 5m×40 PF / 평균 R / MDD | 후반 1년 결과 |
|---|---:|---:|---:|---:|
| 원시 SMC | 522 / -98.03% | 516 / -98.01% | 0.637 / -0.354 / 98.18% | -98.02% (446건) |
| OTE | 52 / -54.16% | 0 / 거래 없음 | — | 거래 없음 |
| MTF | 21 / -12.27% | 18 / -5.76% | 0.829 / -0.126 / 15.97% | +0.66% (6건) |
| 뉴욕 킬존 | 30 / -29.04% | 16 / -3.14% | 0.858 / -0.079 / 19.25% | +16.21% (7건) |

구조 창 제한으로 원시 SMC 손실은 달라지지 않았다. OTE는 15분봉 OTE 영역과 5분봉 스윕이 동시에 맞지 않아 거래가 없었다. MTF와 킬존은 거래 수와 전체 손실이 줄었지만, 전체 BTC 2년 PF는 여전히 1 미만이고 평균 R도 음수다.

## 후반 1년 교차 심볼 확인

후반 1년(2025-10-01~2026-10-01)에 BTC에서 플러스였던 MTF/킬존을 ETH·XRP에 적용했다.

| 전략 | BTC | ETH | XRP |
|---|---:|---:|---:|
| MTF + 5m×40 | +0.66% (6건) | +6.53% (8건) | -5.04% (2건) |
| 뉴욕 킬존 + 5m×40 | +16.21% (7건) | -4.00% (10건) | -9.26% (4건) |

이 플러스 구간은 BTC/ETH의 합계 14건뿐이고 XRP에서는 MTF가 손실이다. 킬존은 BTC 외 두 심볼에서 음수다. 따라서 아직 재현된 우위로 판단할 수 없다.

## 판정

**5분봉 40개 제한은 신호를 줄이는 필터로는 동작하지만, 현재 증거로는 우위를 입증하지 못한다.** MTF가 추가 검증 후보 중 가장 나았지만 2년 BTC 누적 수익률은 -5.76%이고, 플러스인 후반 BTC/ETH 표본도 작다. 킬존은 BTC 후반 성과만 크게 좋아 보이고 다른 심볼은 음수여서 국면 의존 가능성이 높다. 실거래 연결은 보류한다.

SMC의 BOS/스윕, OB, FVG, HTF 방향, LTF 확인을 조합하는 접근은 공개 코드 예시에도 보인다([Frosty098/smc-bos-strategy](https://github.com/Frosty098/smc-bos-strategy), [frankabingale1111/smc-backtest](https://github.com/frankabingale1111/smc-backtest)). 공개 저장소의 성과 수치는 이번 백테스트와 데이터·체결 조건이 달라 비교 근거로 사용하지 않았다.

## 코드와 재현

- `smc_raw_m5_40`, `smc_ote_m5_40`, `smc_mtf_m5_40`, `smc_kz_m5_40` 옵션은 연구용이며 라이브 체인에 추가하지 않았다.
- 기존 신호 함수는 `structure_kl=None`일 때 원래 15분봉 스윙과 기본 BOS/스윕 검색 길이를 유지한다. SMC, OTE, MTF의 기본 호출 결과 동등성을 캔들 샘플에서 확인했다.

```powershell
python projects/deepcoin_bot/backtest/run_v2.py --sym BTC-USDT-SWAP --strat smc_raw_m5_40,smc_ote_m5_40,smc_mtf_m5_40,smc_kz_m5_40 --quiet
python projects/deepcoin_bot/backtest/run_v2.py --sym ETH-USDT-SWAP --strat smc_mtf_m5_40,smc_kz_m5_40 --since 2025-10-01 --quiet
python projects/deepcoin_bot/backtest/run_v2.py --sym XRP-USDT-SWAP --strat smc_mtf_m5_40,smc_kz_m5_40 --since 2025-10-01 --quiet
```

요약과 전체 체결은 `research/backtest_v2/*_m5_40.json` 및 `_since2025-10-01.json` 파일에 저장했다.
