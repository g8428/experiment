# SMC 강의 진입 유형별 독립 백테스트

실행 코드: `run_entrypoint_tests.py`  
개별 체결 기록: `entrypoint_trades.csv`  
요약 결과: `entrypoint_results.csv`

## 테스트 범위와 고정 설정

- 데이터: BTC 1분봉 2024-10-01~2026-10-03, 롱과 가격 미러 숏.
- 테스트 단위: `strats2.py`의 S1, S2, S3d, S3w, S4, S5, S6, S8a, S8b, S8c, S9를 각각 별도 실행. 전략 간 신호 우선순위나 동시 진입은 적용하지 않음.
- 고정값: 구조 바이어스, 셋업 유효기간 3일, 킬존 on, 일·주·월 시가 strict.
- 체결·비용: 공통 `Book2` 시뮬레이터의 taker 수수료 0.06%/편도와 손절·시장가 슬리피지. Maker 결과는 가정치이므로 기본 판정에 쓰지 않음.
- 반기 비교는 표본외 검증이 아니라 기간 안정성 참고치다. 이 자료는 약 2년으로, 최소 5년 권고에는 못 미친다.
- 전략 코드는 기존 강의 구현을 실행한다. 강의에서 수치화하지 않은 기준(유효기간, displacement, swing 필터 등)은 구현 가정이며, 이 결과를 강의 원문이 보장한 성과로 해석하면 안 된다.

재현 명령:

```powershell
python projects/deepcoin_bot/smc_btc/run_entrypoint_tests.py
```

`--both-bias`로 structure/narrative 바이어스를 나눠 실행하거나, `--only S2,S3d`로 일부 유형만 선택할 수 있다. 기본 출력은 구조 바이어스 한 번씩만 집계하여 윈도우 조합에 따른 중복 거래 집계를 막는다.

## 읽을 때 주의할 점

- 이번 결과에서 플러스인 유형은 없다. 다만 S1/S4/S5/S8b의 0~1건은 전략 기각이 아니라, 해당 설정·구현에서 거래가 충분히 나오지 않았다는 뜻이다.
- S2 손절폭 중앙값은 0.056%다. 이는 왕복 taker 비용보다도 좁아서 손절·본절 거래가 R 기준으로 크게 악화된다. 거래별 로그에는 손절 위험폭과 exit 사유를 남겼다. 특히 2026-08-17의 짧은 시간 동안 S2 리클레임 재진입이 연속 기록되므로, 재진입 독립성/동일 셋업 반복 진입을 별도 감사해야 한다.
- S8a는 183건으로 표본은 상대적으로 많지만 평균 -0.864R이고 두 기간 모두 손실이다. 이전 차트 감사에서 S8 계열의 1차 목표가 진입가 근처인 사례가 확인된 바 있어, 결과를 보기 전에 TP 유동성 선택을 다시 점검할 필요가 있다.
- 이전 A/B 요약은 여러 유효기간 결과를 합산해 동일 거래가 중복 포함된다고 명시한다. 이 파일은 3일 한 설정만 보고해 건수·손익 합계가 그 합산표와 직접 비교되지 않는다.
- 이 러너는 현재 `strats2.py`의 A 구현을 실행한다. 수정 중인 `strats_b.py`의 SMC-B는 별도 버전·별도 결과로 검증해야 한다. A와 B 결과를 같은 버전인 것처럼 합치지 않는다.

## 다음 검증 순서

1. S2 재진입 거래를 같은 셋업 ID로 묶어 하나의 아이디어가 다수 독립 거래로 중복 집계됐는지 점검한다.
2. S2·S8a의 손절폭과 TP1 거리를 기초 가격% 기준으로 검사하고, 수수료보다 작은 목표/손절 사례를 따로 집계한다.
3. 강의 명시 규칙과 구현 가정을 분리한 뒤, 위의 각 셋업을 개별 차트 사례로 확인한다.
4. 규칙을 고정한 뒤에만 B 감지기 및 바이어스·킬존 완화안을 한 번에 하나씩 비교한다.
