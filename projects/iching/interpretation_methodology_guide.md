# 주역 AI 해석 방법론

주역 앱(`index.html`) AI 리포트의 해석 방법론과 톤 가이드.

---

## 1. 해석 방법론 — 다산역 + 육효점 하이브리드

다산역(정약용)이 현재 상황을 진단하고, 육효점이 미래·타이밍을 예측한다.

### 다산역 4대 원리

| 원리 | 용도 |
|------|------|
| **추이(推移)** | 12벽괘 흐름(복→임→태→대장→쾌→건→구→둔→비→관→박→곤) 위에서 지금 이 괘가 어느 절기인지. 변효로 흐름을 벗어난 것 자체가 신호. |
| **호체(互體)** | 2·3·4효 → 내호체, 3·4·5효 → 외호체. 겉 괘 안에 숨은 괘. 표면에 보이지 않는 내부 구조(축적된 문제, 숨은 관계 등)를 드러냄. |
| **물상(物象)** | 상괘·하괘의 자연 상징(하늘/땅/우레/바람/물/불/산/못)이 구체적으로 어떤 상황을 형상화하는지. |
| **효변(爻變)** | 변효 위치의 의미: 초효=시작/씨앗, 2효=내부안정/판단, 3효=경계/전환, 4효=외부진입, 5효=군위/중심, 상효=완성/마무리 |

### 육효점 계산 요소

| 요소 | 설명 |
|------|------|
| **납갑(納甲)** | 8궁 배속에 따라 각 효에 60갑자 배당 |
| **세효·응효** | 세효=나, 응효=상대방(질문 대상에 따라 다름) |
| **육친(六親)** | 부모·형제·관귀·처재·자손 — 질문 주제별 주목 육친: 이직=관귀+처재, 연애=관귀, 재물=처재 |
| **육수(六獸)** | 청룡·주작·구진·등사·백호·현무 — 점 친 날 천간 기준, 초효부터 순서대로 배당. 사건 성격 표시. |
| **생극(生剋)** | 오행 상생상극으로 세효·응효·용신 간 에너지 흐름 판단 |
| **형충파해합** | 일진·월건과 각 효 지지 사이의 관계 → 발동 여부·시기 판단 핵심 |
| **공망(空亡)** | 일진 순공 — 해당 효가 비어있는 상태인지 |

육효점 요소는 기계적 나열 금지. "세효는 壬午이고~" 형식이 아니라, 계산 결과를 물상·괘상 해석에 자연스럽게 녹여 서술한다.

### 시기(時期) 판단 — 무엇이 근거이고 무엇이 근거가 아닌가

시기는 **효(爻)에서** 나온다. 점친 날의 일진 자체가 아니다.

| 층 | 근거 | 답하는 것 |
|----|------|----------|
| 다산역 추이 | 본괘·지괘가 12벽괘 절기 어디에 놓이는지(벽괘면 그 달, 비벽괘면 양효 수로 모괘 두 개 사이), 변효가 음→양인지 양→음인지 | 지금이 자라는 국면인지 거두는 국면인지 (계절의 큰 흐름) |
| 다산역 효변 | 변효 위치 (초·이=가까운 시일, 삼·사=중간, 오·상=먼 시점) | 일이 가까운지 먼지 |
| 육효 응기(應期) | 세효·용신·동효(변효 4~5개면 불변효)의 **지지**와 월건·일진의 관계 | 구체적인 달·날 |

육효 응기 원칙:
- 공망 → 출공(값월·충월). 공망+월파(진공)는 값월에만.
- 월파 → 실파(값월·합월)
- 동효 → 합(또는 값)에 응
- 정효 → 충(또는 값)에 응. 월건과 합이면 합처봉충(충 오는 달에 풀림)
- 가까운 일은 일 단위(값일·합일·충일), 먼 일은 월 단위
- 용신은 질문 주제로 정한다(이직·시험·소송=관귀, 재물=처재, 문서·계약·합격=부모, 자녀·치료=자손, 동료·경쟁=형제). 용신이 괘에 없으면(伏神) 더딘 신호.

**근거가 아닌 것**: 오늘 일진 지지의 충·합·공망 달. 이건 괘와 무관하게 그날 점친 사람 전원에게 같은 달을 주므로 시기 근거로 쓰지 않는다. "앞으로 N개월을 달별로 채워라" 같은 고정 윈도우도 금지 — 응기가 하나면 하나만 쓴다.

## 2. 변효 수별 해석 비중

| 변효 수 | 해석 중심 |
|--------|----------|
| 0개 | 본괘 괘사 + 대상전. 六位(초·이·삼·사·오·상) 전체를 始/中/終으로 묶어 흐름으로 읽음. |
| 1개 | 해당 변효 효사 메인. 본괘=맥락, 지괘=귀결. |
| 2개 | 위효(상위 번호, 중심) 위주. 아래효는 보조. |
| 3개 | 세 변효 동등하게. 본괘·지괘 괘사 비교. |
| 4개 | **불변 2효가 중심**. 변하지 않는 자리에서 지괘를 읽음. |
| 5개 | **불변 1효가 중심**. |
| 6개 | 건→용구, 곤→용육. 그 외는 지괘 괘사만. |

## 3. 리포트 구조

1. **총평** — 한 문장 핵심 요약을 소제목으로, 짧은 도입
2. **지금 서 있는 자리** (현재 진단, 다산역) — 물상으로 상황 이미지화, 호체로 숨은 맥락, 변효 위치 의미를 자연스럽게 엮음
3. **이 점괘의 심장** (변효 핵심) — 변효 효사 원문 + 쉬운 풀이. 육효점 세효·응효·육친·육수·생극·공망을 서술형으로 자연스럽게 엮어 구체화
4. **방향** (지괘 귀결) — 지괘 괘사·효사로 향하는 곳의 성격 제시
5. **시기** — 추이로 국면(자라는지/거두는지)과 원근을 먼저, 그다음 응기 후보 중 세효·용신·동효에 해당하는 달·날을 골라 구체적으로 ("~월 초순은 ~, ~일 무렵은 ~"). 근거 블록에 없는 달 금지.
6. **조심할 것** — 경계 포인트 1개로 압축
7. **마무리** — 한두 문장 응축. 선택은 본인 몫이라는 여지를 남기며 종결

## 4. 톤 & 문체 규칙

### 금지

- 항목 병렬 나열 ("이건 이거고 저건 저거고") → 하나의 이야기 흐름으로
- 원론적 설명 과다 ("~라는 것은 ~라는 뜻입니다") → 상황 적용 우선
- 모든 괘 결론이 "중심을 지켜라"로 수렴 → 64괘 각각의 고유 메시지 살릴 것
- 사용자 질문 원문 그대로 인용
- AI 티 나는 표현 일체

### 필수

- 사주 리포트급 완성도 — 결론과 시기 명확
- 효사 원문 인용 + 바로 이어지는 쉬운 풀이
- 구체적 시기 제시 (캘린더 대응) — 단, 응기·추이 근거가 있는 달·날만
- 짧고 힘 있는 문단, 감성적이되 담담한 톤
- 마지막 한 줄 응축 핵심 메시지
- 괘가 답을 정해주지 않는다는 톤 — 방향은 제시하되 최종 선택은 본인 몫
