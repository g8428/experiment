# 주역점사 해석 방법론 가이드

이 문서는 `iching_oracle.html` 프로젝트의 AI 해석 로직(현재는 `generateQ5` / `generateReading` 프롬프트)을 다음 단계로 발전시키기 위해, 별도 대화에서 여러 해석론을 비교 검토하고 최종 방향을 확정한 내용을 정리한 것입니다. 코딩은 진행하지 않았고, 방향만 정한 상태입니다.

---

## 1. 배경 — 왜 방법론을 다시 검토했는가

기존 `generateReading` 프롬프트는 본괘·변효·지괘를 형세/본괘풀이/변효풀이/앞으로의흐름/조언 5개 섹션으로 평면적으로 다뤘습니다. 실제 사용자(재영)가 이직운 등 실전 케이스로 테스트하면서 다음 문제가 드러났습니다.

- 변효 개수와 무관하게 항상 본괘·변효·지괘를 동등하게 다룸 → 정통 서법 규칙과 다름
- 사용자가 입력한 질문 문장을 AI가 그대로 인용 → "AI 티" 남
- 해석이 원론적 설명 위주("이것은 이런 뜻이고, 저것은 저런 뜻이다")로 흘러 지루함
- "앞으로 어떻게 되는지, 언제, 뭘 조심해야 하는지"가 빠져있어 사주 리포트 대비 완성도가 떨어짐

이를 해결하기 위해 네 가지 고전 해석론(서법·의리학·상수학·다산역)과 별도 점술 시스템인 육효점(문왕괘)을 비교 검토했습니다.

---

## 2. 네 가지 고전 해석론 비교

| | 핵심 질문 | 도구 | 강점 | 약점 |
|---|---|---|---|---|
| **서법** (주자 계통) | 이 상황의 구조는 무엇인가 | 괘사·효사·변괘 3층 레이어 | 상황 진단 명확 | 처신 지침 약함 |
| **의리학** (정이천 역전) | 어떻게 처신해야 하는가 | 단전·상전의 도덕적 교훈 | 행동 지침 강함 | 길흉 판정 안 함 |
| **상수학** (경방 계통) | 기운이 어떻게 돌아가는가 | 효위·음양·오행·세효 | 에너지 역학 정밀 | 현상 설명 약함 |
| **다산역** (정약용) | 여러 원리를 겹쳐보면 무엇이 보이는가 | 추이·호체·물상·효변 4원리 | 현재 상황 다층 진단에 매우 강함(사용자 체감 정확도 최고) | 미래 예측·타이밍 기능 없음 |

### 서법의 변효 개수별 해석 규칙 (참고용, 정통 규칙)

- 변효 0개: 본괘 괘사만 봄
- 변효 1개: 변효 효사가 메인, 본괘 괘사는 맥락, 변괘 괘사는 귀결
- 변효 2개: 위쪽(상효) 위주, 아래 효는 보조
- 변효 3개: 본괘·변괘 괘사 비교 중심 (효사보다 괘사)
- 변효 4개: 변괘 하괘 중 불변효를 봄
- 변효 5개: 남은 불변효 하나의 변괘 쪽 효사를 봄
- 변효 6개: 건·곤괘는 용구/용육 예외, 나머지는 변괘 괘사만

### 다산역 4대 원리

- **추이(推移)**: 12벽괘(복→임→태→대장→쾌→건→구→둔→비→관→박→곤) 흐름 위에서 지금 이 괘가 어느 절기에 해당하는지. 변효로 인해 원래 흐름을 벗어나 다른 괘로 가는 것 자체가 의미 있는 신호.
- **호체(互體)**: 2·3·4효로 만든 괘(내호체) + 3·4·5효로 만든 괘(외호체) = 겉의 괘 안에 숨은 또 다른 괘. 표면에 안 보이는 내부 구조(오래 쌓인 문제, 숨은 관계 등)를 드러낼 때 씀.
- **물상(物象)**: 상괘·하괘가 상징하는 자연물(하늘/땅/우레/바람/물/불/산/못)이 구체적으로 어떤 상황을 형상화하는지.
- **효변(爻變)**: 변화가 일어난 효의 위치(초효=시작, 2효=중심의 판단, 상효=끝/극단 등)가 그 변화의 성격을 결정.

## 3. 육효점(六爻占 / 문왕괘) — 별도 점술 시스템

서법·의리학·상수학·다산역은 모두 **주역 원문을 읽는 해석론**입니다. 육효점은 이와 완전히 다른 층위로, 원문을 거의 안 쓰고 **날짜 간지 기반의 독립된 판정 시스템**입니다. "무슨 일이 일어나는가/언제/길흉"에 압도적으로 강하지만 "왜 이런 상황인가"는 설명하지 않습니다.

### 계산 요소

- **납갑(納甲)**: 8궁 배속에 따라 괘의 각 효에 60갑자를 배당 (경방 계통 고정 규칙표 필요)
- **세효(世爻)·응효(應爻)**: 8궁 배속에 따라 정해짐. 세효=나, 응효=상대방(질문에 따라 새 직장/연애 상대 등)
- **육친(六親)**: 부모·형제·관귀(官鬼)·처재(妻財)·자손 — 괘의 오행(궁) 기준으로 각 효에 배당. 질문 주제별로 주목할 육친이 다름 (이직=관귀+처재, 연애=관귀, 재물=처재 등)
- **육수(六獸)**: 청룡·주작·구진·등사·백호·현무 — 점 친 날의 천간 기준으로 초효부터 순서대로 배당. 사건의 성격(길신/흉신, 지연/속도 등)을 나타냄
- **생극(生剋)**: 오행 상생상극으로 세효·응효·용신 간 에너지 흐름 판단
- **형충파해합(刑沖破害合)**: 일진·월건과 각 효 지지 사이의 충돌(沖)·파괴(破)·합화(合) 관계 → 발동 여부와 시기 판단의 핵심
- **공망(空亡)**: 일진 순공 — 해당 효가 "비어있는" 상태인지 (자리가 아직 안 채워짐, 혹은 실체가 약함)

날짜(연월일시)는 시스템에서 `new Date()` 등으로 자동 취득 가능. 60갑자 변환 알고리즘 구현 필요.

## 4. 최종 채택 방향 — 다산역(현재 진단) + 육효점(미래·시기) 하이브리드

### 왜 이 조합인가

- 다산역이 유일하게 "지금 상황을 정확히 짚는다"는 사용자 체감 피드백을 받음
- 하지만 다산역 4원리는 전부 진단 도구라 "앞으로 어떻게, 언제"에 답을 못 함
- 육효점이 유일하게 타이밍·길흉 예측에 강함 (날짜 기반이므로 매번 다른 결과가 나와 반복 사용 시에도 신선함)
- 서법·의리학은 참고하되 메인 구조에서는 제외 (다산역이 진단을, 육효점이 예측을 이미 충분히 커버)
- 결론: **다산역으로 "왜 지금 이 상황인가"를 진단하고, 육효점으로 "앞으로 어떻게·언제·뭘 조심할지"를 예측**하는 두 시스템을 하나의 리포트 안에서 자연스럽게 엮는다.

### 육효점을 기계적으로 나열하지 않는 것이 핵심

육효점 요소(세효·응효·육친·육수·생극·공망)를 "세효는 壬午이고 官鬼입니다. 응효는~" 식으로 딱딱하게 나열하면 사용자가 원하는 감성적 리포트가 안 됨. **계산 결과를 물상·괘상 해석과 자연스러운 문장으로 엮어서 서술**해야 함.

## 5. 톤 & 문체 가이드 — 반복 피드백으로 확정된 규칙

### 절대 하지 말 것

1. **"이건 이거고 저건 저거고" 식 분석 나열** — 항목을 병렬로 설명하지 말고 하나의 이야기 흐름으로 이어갈 것.
2. **원론적 설명 과다** — "~라는 것은 ~라는 뜻입니다" 같은 사전적 설명 반복 지양. 설명보다 상황 적용이 우선.
3. **괘마다 결론이 "중심을 지켜라/바름을 잃지 말라"로 수렴** — 64괘 각각의 고유한 이미지와 메시지를 살릴 것.
4. **사용자 입력 질문 원문을 그대로 인용** — "재영님께서 말씀하신 것처럼..." 식 복붙 금지.
5. **질문 생성 단계(S3)에서 주역 전문용어 노출** — 효/괘/형세/활로 등은 사용자 대면 질문에 쓰지 않음.
6. **AI 티 나는 표현 일체** — 서비스 전체가 "AI가 아니라 전통 점술처럼 느껴지는 것"이 최우선 원칙.

### 반드시 할 것

1. **사주 리포트급 완성도** — 결론과 시기가 명확히 존재해야 함. "990원 사주 사이트처럼"을 기준으로.
2. **효사 원문 인용 + 정확한 오역 없는 해설을 바로 이어 붙임** — 원문만 던지지 말고, 원문 뒤에 쉬운 말로 바로 풀어줄 것.
3. **구체적 시기 구간 제시** — "7월은 ~, 8월 말~9월은 ~" 식으로 실제 캘린더에 대응되는 시간 구간.
4. **짧고 힘 있는 문단, 감성적이되 과장 없이 담담한 톤** — 타로 마스터가 말하듯, 그러나 호들갑스럽지 않게.
5. **마지막에 한 줄로 응축되는 핵심 메시지** — 예: "작은 것에 얽매이지 말 것. 믿음이 가는 곳에서 멈출 것."
6. **괘가 답을 대신 정해주지 않는다는 톤 유지** — 방향과 근거는 명확히 제시하되, 최종 선택은 본인 몫이라는 여지를 남길 것.

## 6. 최종 리포트 구조 템플릿

1. **총평** — 한 문장 핵심 요약을 소제목으로, 이어서 짧은 도입
2. **지금 서 있는 자리** (현재 진단, 다산역) — 상괘·하괘 물상으로 상황을 그림처럼 보여주고, 호체로 드러나는 숨은 맥락, 변효가 일어난 위치의 의미를 자연스럽게 엮음
3. **이 점괘의 심장** (변효 핵심, 서법+육효점) — 변효 효사 원문을 정확히 인용하고 바로 쉬운 풀이. 날짜 정보가 있으면 세효·응효·육친·육수·생극·공망을 서술형으로 자연스럽게 엮어 구체화
4. **방향** (귀결, 변괘 해석) — 변괘 괘사·효사로 향하는 곳의 성격을 제시
5. **시기** — 구체적 시간 구간별 가이드. 육효점 생극·형충 정보가 있으면 여기서 타이밍 근거로 사용
6. **조심할 것** — 경계 포인트 1개로 압축 (여러 개 나열하지 않음)
7. **마무리** — 한두 문장으로 응축, 선택은 본인 몫이라는 여지를 남기며 종결

## 7. 다음 단계 (Claude Code 세션에서 진행할 작업)

1. `generateReading` 프롬프트를 위 6번 구조 + 5번 톤 가이드로 재작성
2. **다산역 자동 계산 로직 추가**
   - 추이: 본괘가 12벽괘 흐름 중 어디 있는지 매핑 테이블
   - 호체: 2·3·4효, 3·4·5효로 새 괘를 도출하는 함수 (기존 `GUA` 룩업 테이블 재사용 가능)
   - 물상: 기존 `TRIG_MAP`의 `nat` 필드 활용 가능
   - 효변: 변효 위치(0~5)에 따른 의미는 고정 텍스트로 매핑 가능
3. **육효점 계산 로직 신규 구축**
   - 60갑자 날짜 변환 알고리즘
   - 64괘 8궁 배속표
   - 각 괘·각 효의 납갑 간지 배당표 (64×6 = 384칸)
   - 8궁별 세효·응효 위치표
   - 육친 배당 규칙 함수
   - 육수 배당표
   - 생극·형충파해합 판정 함수
   - 공망 계산 함수
4. 프롬프트에는 계산 결과를 구조화해서 전달하고, AI가 5번 톤 가이드에 따라 자연스러운 리포트로 풀어쓰게 함
5. S3 질문 생성 로직은 기존 그대로 유지
