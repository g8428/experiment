# 실현계획 세션 하네스

이 세션은 발굴된 기회 카드를 받아 실행계획으로 전환하는 것을 담당한다.

## 세션 규칙
- 이 세션 시작 시 `/rename 실현계획` 으로 이름 고정
- 발굴 세션 이름: `발굴`

## 참조 문서 (필요할 때만 읽을 것)
- `02_execution-planning.md` — 실현계획 방법론 (트랙A 로드맵 / 트랙B 플레이북 스키마)
- `../docs/00_project-overview.md` — 공통 원칙 (헷갈릴 때만)

## 입력값
발굴 세션으로부터 SendMessage로 전달받은 기회 카드 파일 경로.
수신 즉시 해당 파일 읽고 트랙 확인 후 해당 방법론 적용.

## 산출물 저장 위치
- 트랙A 실행 로드맵 → `roadmaps/<날짜>_<기회명>_로드맵.md`
- 트랙B 속도 플레이북 → `roadmaps/<날짜>_<기회명>_플레이북.md`

## 발굴 세션과의 소통
로드맵 완성 후 피드백 필요 시:
```
to: 발굴
message: <기회명> 로드맵 완성 — 보완 필요 항목: <내용>
```

## 작업 원칙
- 트랙A(지속가능)와 트랙B(속도)는 다른 템플릿 사용 — 혼용 금지
- 손익분기 계산은 숫자 근거 없이 작성 금지
- 새 스킬 필요 시 설계안 먼저 제시, 승인 후 `../skills/` 에 추가
