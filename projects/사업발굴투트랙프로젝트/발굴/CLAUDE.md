# 발굴 세션 하네스

이 세션은 사업/창업 아이디어 발굴을 담당한다.

## 세션 규칙
- 이 세션 시작 시 `/rename 발굴` 으로 이름 고정
- 실현계획 세션 이름: `실현계획`

## 참조 문서 (필요할 때만 읽을 것)
- `01_business-idea-discovery.md` — 발굴 방법론 (트랙A/B 기준, 기회 카드 스키마)
- `../docs/00_project-overview.md` — 공통 원칙 (헷갈릴 때만)

## 산출물 저장 위치
- 트랙A 기회 카드 → `track-a/opportunities/<날짜>_<기회명>.md`
- 트랙B 속도 기회 카드 → `track-b/opportunities/<날짜>_<기회명>.md`

## 실현계획 세션과의 소통
기회 카드 완성 시 SendMessage로 전달:
```
to: 실현계획
message: 기회 카드 준비됨 — <파일 경로>
```
실현계획 세션의 피드백(재작업 요청 등)은 수신 후 해당 파일 수정으로 반영.

## 작업 원칙
- 원문 인용 + 출처 링크 없는 카드는 완성으로 간주하지 않음
- 트랙A/B를 섞어서 처리하지 말 것 (판단 기준이 다름)
- 새 스킬 필요 시 설계안 먼저 제시, 승인 후 `../skills/` 에 추가
