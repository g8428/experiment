# 사업/창업 아이디어 발굴 — 세부 목적과 방법

`00_project-overview.md`의 공통 원칙을 전제로 한다.

## 목적

"무엇을 할 것인가"를 근거 기반으로 찾아낸다. 두 개의 서로 다른 트랙으로 나눠서 운영한다.

- **트랙 A — 지속가능 사업 발굴**: 반복적인 페인포인트 + 시장 공급 공백을 근거로, 몇 달 단위로 키울 수 있는 사업 기회를 찾는다.
- **트랙 B — 순간 트렌드 포착**: "말랑이"류처럼 짧은 기간에 폭발했다가 꺼지는 상품/트렌드를 타이밍 안에 잡아내는 기회를 찾는다.

두 트랙은 판단 기준과 속도가 다르므로 별도 파이프라인으로 운영한다.

---

## 트랙 A: 지속가능 사업 발굴

### 판단 기준
- 감정 키워드 빈도가 아니라 **원문 인용 + 지불의사(WTP) 신호**
  - 나쁜 예: "불편하다는 댓글이 많다"
  - 좋은 예: "'이거 있으면 한 달에 3만원은 낼 것 같다'는 원문과 링크"
- 수요-공급 교차: 검색량 증가율 vs 실제 공급자(브랜드/업체) 밀도

### 3단 파이프라인

1. **신호 발견 (릴스/쇼츠)**
   - vidIQ 아웃라이어(`vidiq_outliers`, `vidiq_ig_accounts_from_outliers`)로 특정 카테고리에서 급상승 중인 콘텐츠 탐지
   - `video-content-analysis` 스킬로 해당 콘텐츠의 후킹 포인트·댓글 반응 파악
   - 이 단계의 결과는 "가설"이지 결론이 아님

2. **커뮤니티 검증 (텍스트 마이닝)**
   - 대상: 네이버 카페, 디시인사이드, 블라인드, 에브리타임, 쿠팡/스마트스토어 리뷰
   - 방법: "불편하다/화난다"류 감정어가 아니라, 지출·구매 의향이 담긴 문장을 우선 추출
   - 각 페인포인트마다 원문 인용 2~3개 + 링크를 반드시 첨부 (WeakPoint 방식)
   - 경쟁 제품의 1~2점 리뷰도 별도로 마이닝해서 "왜 화났는지" 구체적 기능 단위로 정리 (PainMap 방식)

3. **시장 규모 확인**
   - 네이버 데이터랩 검색량 추이 vs 실제 등록 업체/브랜드 수 비교
   - 검색량은 느는데 전문 브랜드가 없는 카테고리를 우선순위로
   - BigIdeasDB식 gap score(0~10)를 자체적으로 매겨서 카테고리 간 비교 가능하게 함

### 산출물: 기회 카드 (Opportunity Card)
각 기회는 아래 형식으로 통일해서 출력한다.

```
- 기회명:
- 트랙: A (지속가능)
- 페인포인트 요약: (원문 인용 포함)
- WTP 근거: (구체적 금액/지출 언급 있으면 표기)
- 시장 갭 스코어: /10 (근거: 검색량 추이 vs 공급자 밀도)
- 출처 링크: [ ]
- Go/Pivot/Stop 1차 판정:
```

## 트랙 B: 순간 트렌드 포착 (말랑이류)

### 판단 기준
- 감이 아니라 **모멘텀 스코어**와 **단계(Phase)**
- Phase 4단계: Emerging → Growing → Peak → Declining
- 진입은 Emerging~Growing 구간, 모멘텀 스코어 60점 이상일 때만 (Peak 진입 시 이미 경쟁 과열 + 마진 압박 상태)

### 왜 트랙 A와 다른 파이프라인이 필요한가
- 판단까지 며칠 안에 끝나야 함 — 챗봇에 매번 물어보는 구조로는 타이밍을 놓침
- WTP 검증(트랙 A의 핵심)을 기다릴 시간이 없음 — 대신 모멘텀 속도 자체가 신호

### 필요한 신호와 자동화
1. **릴스/틱톡 조회수 급상승 곡선** — vidIQ 아웃라이어를 정기적으로(예: 매일) 자동 실행하는 모니터링 스킬 필요 (사람이 매번 물어보면 이미 늦음)
2. **광고주 수 (포화도)** — 특정 제품에 광고를 태우는 셀러가 몇 명인지로 이미 알려졌는지 판단 (Pipiads류 로직)
3. **소싱 가능 여부** — 1688/알리익스프레스 발주량·재고·가격 추이로 지금 뗴올 수 있는 물건인지 확인 (AliShopping Tools 로직)

### 산출물: 속도 기회 카드
```
- 상품/트렌드명:
- 트랙: B (순간)
- 현재 Phase: Emerging / Growing / Peak / Declining
- 모멘텀 스코어: /100
- 광고주 수(포화도 추정):
- 소싱 리드타임 추정:
- 데드라인: (이 날짜까지 진입 안 하면 Peak 진입 예상)
```
