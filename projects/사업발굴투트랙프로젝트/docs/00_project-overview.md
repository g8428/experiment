# 1인 기업가 AI 에이전트 프로젝트 — 개요

## 배경

경제적 자유와 1인 기업가로서의 독립을 목표로, AI 자동화·AI 에이전트를 활용해 사업 관련 업무 전 과정을 대행할 "AI 사원 조직"을 구축한다. 이 프로젝트는 두 개의 축으로 나뉜다.

1. **사업/창업 아이디어 발굴** — 무엇을 할지 찾는다
2. **실현계획 수립** — 찾은 것을 어떻게 실행할지 짠다

이 문서는 두 축 모두에 적용되는 공통 원칙과 전체 구조를 정의한다. 각 축의 세부 목적·방법은 별도 파일(`01_business-idea-discovery.md`, `02_execution-planning.md`)에서 다룬다.

## 공통 원칙

### 1. 근거 기반 (Evidence-first)
"AI가 그럴듯하게 만들어낸 감(vibes)"이 아니라, 실제 데이터·원문 인용·출처 링크가 붙은 결론만 채택한다. 감성 키워드 카운팅이나 막연한 트렌드 추정은 참고자료 수준으로만 취급하고, 의사결정 근거로 쓰지 않는다.

### 2. 두 개의 시간축을 분리해서 다룬다
- **지속가능 트랙**: 몇 주~몇 달 걸려도 되는 리서치형 기회 (WTP 검증 필요)
- **속도 트랙**: 며칠 안에 판단해야 하는 순간적 기회 (말랑이류 — 모멘텀 스코어 기반)

이 둘은 판단 기준, 필요한 자동화 수준, 실행 속도가 완전히 다르므로 하나의 파이프라인으로 뭉뚱그리지 않는다.

### 3. 자동화 우선, 특히 시간이 걸리는 신호일수록
챗봇 대화로 매번 물어보는 방식은 지속가능 트랙에는 맞지만, 속도 트랙(순간 트렌드)에는 치명적으로 늦다. 속도가 중요한 신호는 주기적 모니터링/알림 스킬로 미리 구축해둔다.

### 4. 비용(크레딧) 의식
vidIQ 같은 유료 API 기반 도구를 쓸 때는 항상 크레딧 잔량과 소모량을 계산하고, 저비용 필터링(지표 확인) → 고비용 심층분석(씬별 분석) 순으로 단계를 나눈다.

### 5. 벤치마킹은 실제 사례 기반으로
아이디어 자체는 참신할 필요 없다. 이미 해외에서 검증된 방법론(PainMap, BigIdeasDB, WeakPoint, WorthBuild, Kalodata, AliShopping Tools 등)의 핵심 로직을 한국 시장/한국어 데이터에 맞게 이식하는 것을 우선한다.

## 전체 구조

```
[사업/창업 아이디어 발굴]  →  [실현계획 수립]
        ↓                          ↓
  기회 카드(Opportunity Card)  →  실행 로드맵
  (근거 + 점수 + 출처)            (소싱/마케팅/운영/재무)
```

두 축은 독립적으로 작동하되, 발굴 단계의 산출물("기회 카드")이 실현계획 단계의 입력값이 되는 구조로 연결한다.

## 기존 보유 자산

- **video-content-analysis 스킬**: 릴스/쇼츠/틱톡 링크를 씬별로 분석하고, 자체 5축 루브릭으로 성과를 예측하는 스킬. 발굴 단계의 "릴스 신호 발견" 레이어에서 재사용.
- **vidIQ MCP 연동**: 아웃라이어(급상승 영상) 탐지, 인스타 릴스 지표 조회, 계정 오너 인사이트 등.

## 참고할 실제 사례 (도구/방법론)

| 분류 | 도구 | 핵심 로직 |
|---|---|---|
| 페인포인트 마이닝 | PainMap | 커뮤니티 원문 인용 + WTP(지불의사) 신호 추출 |
| 시장 갭 스코어링 | BigIdeasDB | 100만+ 불만 데이터로 카테고리별 gap score 산출 |
| 근거 검증형 리서치 | WeakPoint | 합성 점수 없이 원문·출처 URL만 근거로 사용, 기계적 검증 |
| 종합 검증 리포트 | WorthBuild | Go/Pivot/Stop 판정 + TAM/SAM/SOM + 경쟁사 인텔리전스 |
| 순간 트렌드 모멘텀 | Kalodata, AliShopping Tools | Emerging→Growing→Peak→Declining 단계 + 모멘텀 스코어 |
| 광고 스파이 | Pipiads류 | 특정 제품에 광고 태우는 셀러 수로 포화도 판단 |

이 표는 두 세부 문서 전반에서 반복 참조된다.
