# 1인 기업가 AI 에이전트 프로젝트

두 워크스트림: (A) 사업/창업 아이디어 발굴, (B) 실현계획 수립.

## 참조 문서 (필요할 때만 읽을 것 — 전체를 매번 다시 읽거나 재출력하지 말 것)
- `docs/00_project-overview.md` — 공통 원칙, 두 트랙(지속가능/순간트렌드) 구분, 전체 아키텍처
- `docs/01_business-idea-discovery.md` — 발굴 방법론 + "기회 카드" 출력 스키마
- `docs/02_execution-planning.md` — 실행계획 방법론 + "실행 로드맵/속도 플레이북" 출력 스키마

## 핵심 원칙 (요약)
1. 원문 인용 + 출처 링크 없는 결론은 채택 금지 (감성 키워드 카운팅만으로 결론 내지 말 것)
2. 트랙 A(지속가능·WTP검증)와 트랙 B(순간트렌드·모멘텀스코어)는 판단 기준과 속도가 다르므로 절대 같은 파이프라인으로 섞지 말 것
3. 각 스킬의 출력은 반드시 docs/에 정의된 카드/로드맵 스키마의 필드명을 그대로 따를 것 (스키마 임의 변경 금지)
4. vidIQ 등 크레딧 기반 API는 저비용(지표 확인) → 고비용(심층분석) 순으로 단계화

## 현재 보유 스킬
- `video-content-analysis` — 릴스/쇼츠/틱톡 씬별 분석 + 5축 성과예측 루브릭 (트랙 A "신호 발견" 단계, 트랙 B "모멘텀 확인" 단계에서 재사용)

## 작업 방식
- 새 스킬/에이전트를 만들 때는 항상 설계안(SKILL.md 초안)을 먼저 제시하고 승인받은 뒤 구현할 것
- 구현 완료 후에는 반드시 실제 샘플 입력 1개로 실행해보고 출력 스키마 준수 여부를 스스로 검증할 것
