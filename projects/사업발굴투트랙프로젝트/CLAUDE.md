# 1인 기업가 AI 에이전트 프로젝트

두 세션이 분리 운영되며 기회 카드를 매개로 소통한다.

## 세션 구조
| 세션 | 이름 | 시작 폴더 | 역할 |
|---|---|---|---|
| 발굴 | `발굴` | `발굴/` | 트랙A/B 기회 카드 생성 |
| 실현계획 | `실현계획` | `실현계획/` | 기회 카드 → 로드맵/플레이북 전환 |

각 세션은 해당 폴더에서 열면 CLAUDE.md가 자동 로드된다.

## 참조 문서 (필요할 때만 읽을 것)
- `docs/00_project-overview.md` — 공통 원칙, 전체 아키텍처

## 보유 스킬
- `skills/` — 구축된 스킬 목록 (없으면 빈 폴더)

## 핵심 원칙 (요약)
1. 원문 인용 + 출처 링크 없는 결론은 채택 금지
2. 트랙A(지속가능)와 트랙B(순간트렌드)는 절대 같은 파이프라인으로 섞지 말 것
3. 각 스킬 출력은 반드시 docs/ 스키마 필드명 그대로
4. vidIQ 등 크레딧 기반 API는 저비용 → 고비용 순으로 단계화
