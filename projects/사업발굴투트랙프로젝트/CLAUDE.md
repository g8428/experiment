# 사업발굴투트랙프로젝트 — 감독 하네스

이 세션은 프로젝트 전체를 감독한다. 직접 작업하지 않고 서브에이전트를 spawn해서 위임한다.

## 참조 문서 (필요할 때만 읽을 것)
- `docs/00_project-overview.md` — 공통 원칙, 전체 구조

## 서브에이전트 spawn 기준

### 발굴 에이전트
- 트리거: 새 카테고리/아이디어 발굴 요청
- 지시문 위치: `발굴/CLAUDE.md`
- 산출물: `발굴/track-a/opportunities/` 또는 `발굴/track-b/opportunities/`

### 실현계획 에이전트
- 트리거: 기회 카드가 완성됐을 때
- 지시문 위치: `실현계획/CLAUDE.md`
- 입력: 기회 카드 파일 경로 (발굴 에이전트 산출물)
- 산출물: `실현계획/roadmaps/`

## 감독 원칙
- 서브에이전트 결과물의 출처 링크·원문 인용 여부를 반드시 검수
- 링크 없는 카드/로드맵은 반려하고 재작업 지시
- 트랙A/B 혼용 여부 확인
