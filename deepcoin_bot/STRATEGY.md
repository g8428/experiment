## 2. 진입 조건 (패턴 학습 결과 반영)

### 2-1. 높은 확률 진입 조건 ✅

**패턴**: `london + BOS + FVG진입 + OB≥3 + FVG≥2 + no_sweep`
- 승률: 100% (1/1, 누적 +11.77%)
- 조건:
  - 세션: 런던 킬존 (UTC 07~10 / KST 16~19)
  - BOS 확인 (ChoCh 허용)
  - POI: FVG 진입 (OB재터치보다 우선)
  - OB 개수 ≥ 3 (구조 강도 확인)
  - Bull/Bear FVG 개수 ≥ 2
  - 스윕 없음 (no_sweep)
- **액션**: 풀 사이즈 진입 허용

### 2-2. 주의 진입 조건 ⚠️

**패턴**: `london + 없음/BOS + OB재터치 + sweep`
- 승률: 0~33% (복수 패턴)
- 조건 완화 시 손실 편향
- **액션**: 포지션 크기 50% 축소, RR≥2.0 강제

### 2-3. 금지 조건 ❌

**패턴**: `newyork + BOS + OB재터치 + sweep`
- 승률: 0% (3/3 패턴 모두 손실)
- 뉴욕 세션 + BOS + OB재터치 + 스윕 조합
- **액션**: 진입 금지

## 4. SMC 기반 진입 원칙

### 구조 확인 순서 (필수)
1. **1H EMA 추세 방향** 확인 → 역추세 방향 차단
2. **BOS/ChoCh** 확인 → 방향성 결정
3. **OB/FVG POI** 도달 확인 → 진입 타이밍
4. **킬존** 확인 → 세션 필터
5. **스윕 여부** 확인 → 스윕 없으면 가중치 up

### SL/TP 설정
- **LONG SL**: Bullish OB 하단 × 0.9995
- **SHORT SL**: Bearish OB 상단 × 1.0005
- **TP1**: 반대편 FVG 하단 or 직전 스윙 레벨
- **TP2**: 유동성 풀 (등고/등저점 클러스터)

## 6. 자가진화 규칙

### 패턴 통계 업데이트 조건
- 패턴 키당 **≥5 거래** 누적 시 통계 유의미
- 승률 ≥ 70% → 가중치 증가 / 허용 조건으로 추가
- 승률 ≤ 30% (5+거래) → 제한 조건으로 추가
- 승률 ≤ 20% (3+거래) → 즉시 금지 조건 고려

### 원칙 업데이트 절차
1. `python evolution/review_trades.py` 실행
2. `pattern_stats.json` 의 `pending_updates` 확인
3. 조건 충족 패턴 → `STRATEGY.md` 섹션 2 업데이트
4. 버전 올리기 (v1.x → v1.x+1)
5. `## 진화 이력` 에 변경 내용 기록
6. git 커밋
