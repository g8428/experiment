# 개발 참고 자료 (agent-dev)

AI 에이전트·앱을 만들 때 참고하려고 모아 둔 외부 자료 분석. 영상·글을 그대로 믿지 않고 **크로스체크한 결과**와 **이 레포에서 쓰는 법**을 같이 적는다.

새 프로젝트를 시작하거나 에이전트·스킬을 만들기 전에 아래 표에서 관련된 것을 먼저 읽는다.

| 날짜 | 자료 | 언제 읽나 | 핵심 |
|---|---|---|---|
| 2026-11-01 | [에이전트 대신 스킬 (릴스)](2026-11-01-reel-skills-over-agents.md) | 에이전트·스킬을 새로 만들 때 | 범용 에이전트 하나 + 작업별 SKILL.md. 맨 위 `name`·`description` 필수, 완료 기준은 증거로, 틀리면 매뉴얼을 고친다 |
| 2026-11-01 | [앱 출시 전 법적 체크리스트 (릴스)](2026-11-01-reel-app-launch-legal-checklist.md) | 사용자 정보를 받거나 결제·광고 메시지가 있는 앱·웹을 만들 때 | 데이터 지도 → 문서 → 화면(다크패턴 6유형·접근성) → 메시지(광고 수신 동의) → 증거. 한국은 만 14세·정보통신망법 제50조 기준 |

## 추가하는 법

- 파일명: `YYYY-MM-DD-<종류>-<주제>.md` (종류: reel, article, talk, doc …)
- 구성: 원본 링크 · 한 줄 결론 → 내용 요약 → 크로스체크 표(맞음/과장/틀림 + 근거) → 이 레포에서 쓰는 법 → 출처
- 이 README 표에 한 줄 추가
