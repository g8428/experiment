# 릴스 분석: "앱 만들다 고소당하기 전에, 클로드한테 꼭 시켜야 할 20가지"

- 원본: https://www.instagram.com/reel/DfFQMBTM3TO/ (34초, 리스트형)
- 분석: vidIQ 장면 분석 + 웹 크로스체크(한국 법 기준), 2026-11-01
- 한 줄 결론: **출시 전 체크리스트로 쓸 만하다. 다만 한국 기준으로는 순서·근거가 다르고, 영상에 없는 중요한 항목(다크패턴 6유형, 광고 수신 동의)이 있다.**
- ⚠️ 법률 자문이 아니다. 아래 근거는 2차 자료(로펌 칼럼·언론·블로그) 기반이라, 실제 출시 전엔 법령 원문 또는 전문가 확인이 필요하다.

## 영상의 20가지 (원문 그대로)

1. 개인정보처리방침 2. 이용약관 3. 환불정책 4. 쿠키정책 5. 쿠키동의배너 6. 입력 양식의 동의항목 확인 7. 불필요한 개인정보 수집 안 하기 8. 외부 SDK 점검 9. 원치 않는 선택으로 유도하지 않기 10. 숨겨진 요금 없애기 11. 가짜 후기 없애기 12. 근거 없는 주장 없애기 13. 이미지 대체 텍스트 14. 글자·배경 색상 대비 15. 키보드만으로 이동 16. 사업자 정보 추가 17. 아동 정보 수집 시 나이 확인 절차 18. 이메일 수신거부 링크 19. 이미지·글꼴 이용권 확보 20. 개인정보 삭제 요청 기능

## 크로스체크 (한국에서 서비스할 때)

| 영상 항목 | 판정 | 한국 기준 메모 |
|---|---|---|
| 1 개인정보처리방침 | 맞음, 필수 | 개인정보 보호법 제30조: 정하고 쉽게 확인할 수 있게 공개해야 한다 |
| 2·3 이용약관·환불정책 | 맞음 | 온라인 판매면 전자상거래법상 청약철회(환불) 안내가 핵심 |
| 4·5 쿠키정책·동의배너 | 조건부 | GDPR(유럽 이용자)에선 사전 동의가 필수. 한국은 쿠키 배너 자체를 명시한 조문을 이번에 확인하지 못했다 — 맞춤형 광고·분석 도구(행태정보)를 쓰면 처리방침 공개와 동의 여부를 따로 확인할 것 |
| 6·7 동의항목·최소 수집 | 맞음 | 한국 법은 동의 중심이라 필수/선택 동의 분리가 특히 중요 |
| 8 외부 SDK 점검 | 맞음 | SDK가 가져가는 정보도 처리방침(제3자 제공·처리위탁)에 반영해야 한다 |
| 9·10 원치 않는 선택 유도·숨은 요금 | 맞음, 그리고 **이미 법** | 개정 전자상거래법(2025-02-14 시행)이 다크패턴 6유형을 규제: 순차공개 가격책정, 숨은갱신, 특정옵션 사전선택, 잘못된 계층구조, 취소·탈퇴 방해, 반복간섭. 2025-10 첫 제재(쿠팡 등 4개사)라는 보도 있음. 과태료 시점은 자료마다 달라 원문 확인 필요 |
| 11·12 가짜 후기·근거 없는 주장 | 맞음 | 표시광고법 영역 |
| 13~15 대체텍스트·색 대비·키보드 이동 | 맞음 | 장애인차별금지법 제20·21조로 민간 사이트의 대체텍스트 누락을 차별로 본 판결이 있다. 4.5:1 대비는 WCAG 기준(KWCAG 원문 수치는 미확인). 민간 의무 범위는 미확인 |
| 16 사업자 정보 | 맞음, 판매하면 필수 | 전자상거래법상 상호·대표자·사업자등록번호·통신판매업 신고번호 등 표시 |
| 17 아동 정보 | 맞음, 기준은 **만 14세** | 한국은 만 14세 미만이면 법정대리인 동의(개인정보 보호법 제22조의2). 영상의 COPPA(미국, 13세)와 다르다 |
| 18 이메일 수신거부 링크 | 부족 | 정보통신망법 제50조: 광고성 정보는 **명시적 사전 동의**가 원칙, 전송자·수신거부 방법 표시, 야간(21~08시) 별도 동의, **2년마다 수신 동의 재확인**. 수신거부 링크만으로는 모자란다 — 마케터에게 특히 중요 |
| 19 이미지·글꼴 이용권 | 맞음 | 상업적 이용 가능 라이선스 확인 |
| 20 개인정보 삭제 요청 | 맞음 | 열람·정정·삭제 요구권. 탈퇴 방해는 다크패턴(취소·탈퇴 방해)에도 걸린다 |

## 개발할 때 쓰는 법 (이 레포 기준)

출시 직전에 몰아서 하지 말고, 기획 단계에서 Claude에게 아래 순서로 시킨다. 반복해서 쓸 거면 `.claude/skills/launch-legal-check/SKILL.md`로 만들 것(→ `2026-11-01-reel-skills-over-agents.md`의 스킬 작성법).

1. **데이터 지도부터** — "이 서비스가 수집하는 개인정보 필드, 저장 위치, 쓰는 외부 SDK·API를 표로 뽑아라." (항목 6·7·8·17·20의 입력이 된다)
2. **문서 초안** — 데이터 지도를 근거로 처리방침·약관·환불정책·사업자 정보 푸터 초안. 지도에 없는 항목은 쓰지 않게 한다.
3. **화면 점검** — 가입·결제·구독 해지·탈퇴 화면 코드를 주고 다크패턴 6유형 + 접근성(대체텍스트·4.5:1 대비·키보드 이동) 점검.
4. **메시지 점검** — 광고 메일·푸시·알림톡 템플릿에 (광고) 표시, 전송자, 수신거부 방법, 야간 동의, 2년 재확인 일정이 있는지.
5. **완료 기준(증거)** — 체크리스트 항목마다 증거를 남긴다: 처리방침 URL, 동의 화면 스크린샷, 대비 측정값, 키보드 탐색 녹화, 탈퇴 경로 단계 수. "괜찮아 보임" 금지.
6. 마지막으로 법령 원문 또는 전문가 확인 (특히 결제·아동·해외 이용자가 있으면).

## 콘텐츠 형식 메모 (내 채널 참고)

- 훅: 손실 회피("고소당하기 전에") + 숫자("20가지") + 시간 약속("34초 안에 설명"), 화면 오른쪽 아래 카운트다운 타이머로 끝까지 보게 만든다.
- 구성: 말 없이 리스트가 1번부터 채워지는 속사포 리스트형. 말로 하는 CTA가 없고, 완성된 리스트 화면 자체가 저장·캡처를 부른다.
- 응용: "재구매율 올리기 전에 CRM 메시지에 꼭 넣어야 할 N가지(30초)" 같은 마케터용 리스트형으로 바로 쓸 수 있는 틀.
