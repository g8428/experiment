# 알뜰폰 요금제 모니터링 자동화

매일 1회, 조건에 맞는 알뜰폰(MVNO) 특가 요금제를 자동으로 검색해서 Slack DM으로 전달하는 프로젝트.

## 목적

알뜰폰 요금제 특가는 커뮤니티(클리앙 알뜰구매, 뽐뿌 등)와 비교 사이트(모요, 알뜰폰허브)에 파편적으로 올라온다.
매번 직접 찾아보는 대신, 조건에 맞는 것만 걸러서 매일 아침 자동으로 받아본다.

## 필터 조건

| 항목 | 조건 |
|---|---|
| 월 요금 | 2만원대 이하 (프로모션 종료 후 정상가 기준) |
| 약정 형태 | 평생 유지 가능한 가격이거나, 7개월 등 단기 갈아타기용 특판이어도 OK |
| 데이터 | 10GB + 일 2GB 이상, 또는 40GB 이상 |
| 통화 | 조건 없음 (적어도 무관) |
| 위약금/약정 | 위약금 조건이 짧거나 없는 것 우선 (장기 위약금 조건 있는 특가는 제외) |
| 테더링/핫스팟 | 가능해야 함 |
| 로밍 | 가능해야 함 |

## 검색 소스

- 클리앙 알뜰구매 게시판 (`clien.net/service/board/jirum`) — 커뮤니티가 매달 정리하는 특가 리스트
- 뽐뿌 통신 게시판
- 모요 (moyoplan.com) — 요금제 비교/필터
- 알뜰폰허브 (mvnohub.kr)
- 각 통신사 다이렉트 사이트 (A모바일, 티플러스, U+유모바일, 우체국알뜰폰 등)

## 실행 방식

1. 매일 1회 스케줄된 Claude 세션이 위 소스를 웹 검색으로 조회
2. 위 필터 조건에 맞는 요금제만 추림 (조건 미달은 제외, 애매하면 이유와 함께 후보로만 표시)
3. 결과를 정리해서 Slack "나에게 보내기" (channel_id: `U0AEWE72USG`)로 발송
4. 조건에 맞는 특가가 하나도 없는 날은 "오늘은 조건에 맞는 특가 없음"으로 짧게 발송 (스팸 방지)

## 알림 채널

- **방식**: Slack DM (본인)
- **이유**: 카카오톡 "나에게 보내기"는 연동 커넥터가 없고, 공식 API를 쓰려면 만료되는 액세스 토큰을 직접 관리해야 해서 당장은 이미 연결된 Slack DM으로 대체함
- 추후 카카오 API 토큰 관리 방법이 마련되면 전환 가능

## 스케줄

- 매일 1회 (등록: Cowork 스케줄 태스크, cron 방식)
